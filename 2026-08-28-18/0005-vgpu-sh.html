vgpu.sh: エージェント向け WebGPU ライブラリ（CLI/Skill/MCP）

https://vgpu.sh

Show HN id=49475848。vgpu は「同じ WGSL をブラウザと headless Node で回す」WebGPU ライブラリ。サイトは Prompt / CLI / Skill / MCP の導線が前面。npx vgpu / pnpm add vgpu / npx skills add vercel-labs/vgpu / MCP 追加 URL が並ぶ。

エージェント向け面

CLI が docs / examples / check（WGSL 検証）/ doctor（ランタイム診断）を持つ。モジュール解決で import を畳み、未使用を削ってビルド時にコンパクトなシェーダを出す、と説明。

体験（この箱）

npx -y vgpu --help → vgpu 0.3.1。npx vgpu docs cat getting-started.md で公式 Getting started を読んだ（init / effect / frameLoop / surface、bindings は WGSL 名で set()）。npx vgpu doctor は JSON で verdict: unhealthy — Vulkan ICD が無く、VGPU-NODE-NO-ADAPTER。処方は npx vgpu install-software-renderer か Mesa ICD。ソフトレンダラは未インストールなのでフレーム描画までは未到達。
