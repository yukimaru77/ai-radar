codex-host: Codex Desktop で Pi/CC/OMP/Grok/DSH を実行

https://github.com/BytePioneer-AI/codex-host

README（中文）を開いた。MIT。作者の立場は「最良のデスクトップ体験は Codex Desktop、でも最良のハーネスは Codex だけではない」。実行側を差し替えつつ GUI を残す。

入れ方

npm i -g @codexhost/cli → codexhost。Releases に macOS/Windows 包。Linux x64 は別ドキュメント。macOS 初回は quarantine 外し、Windows 緑版 Codex は CODEXHOST_INSTALL_ROOT を立てる、とトラブルシュートあり。

対応ハーネス（README表）

Codex / Pi / Oh My Pi / Claude Code / Grok Build / DeepSeek Harness。スクショ説明では Agent・Model セレクタ、Usage（コンテキスト・キャッシュ・費用）、Grok の 5h/7d 残、Mermaid の可視化など。LD 2825164 ではツール呼び出し・質問ポップ・Diff・Fork・subAgent まで、と自己申告。
