Sentō: 会社の記憶をチャットの私有メモリに置くな

https://www.sentohq.com/posts/company-memory-should-not-live-in-chat

2026-08-27 公開の論考（約7分）。HN id=49475761。個人の private memory は便利だが、チームでは「五つのAIが五つの会社を覚え、どれも監査不能」になる、が中心。

具体例

コールドアウトリーチの宛先を変えたら、共有ファイルを3回編集しただけで午後には全エージェントが新読者向けになった、と。個人メモリが旧ピッチを握っていたら、どの下書きがどの版由来か何週間も探すことになる。だから彼らはエージェントの個人メモリをOFFにして運用している、と明言。

置き場

トーン好みは個人でよいが、プロダクトの誰向け・価格・ロードマップ・法務承認・営業が約束してよいことは会社コンテキストで、所有者・版履歴・権限・変更監査が要る。Sentō 側の実体は shared workspace の entity。製品トライアル自体はこの箱では未実施（記事のみ）。
