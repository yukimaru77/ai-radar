Terminal-Bench 4.0 — 資源校正・飽和タスク除去、GLM-5.3≈Fable 5（誤差内）

https://www.tbench.ai

tbench.ai の4.0発表＋リーダーボード。資源（時間・CPU・メモリ）を校正し、タスク修正、飽和タスクを外した。エージェントタイムアウト／エラーが3.0より減り、残る失敗は主にモデル拒否と出力トークン上限。全タスクのエージェントタイムアウトは一律8時間。

DELIVER側の数字（リーダーボード読み）: GLM-5.3 max 41.8%±3.2%（$2.7k）vs Fable 5 max 44.5%±3.8%（$7.3k）。Opus 5 + Claude Code 51.8%。Sonnet 5は12.4%でノイズ大（21.6Bトークン vs Opusの6.5B、タイムアウトと出力上限）。Reddit「誤差を見ればGLM≈Fable」はこの表。

バージョンが4.0な理由: 連続ベンチマーク＋セマンティックバージョニング。資源変更とタスク集合の削除は破壊的変更なので再実行が必要。harbor run -d terminal-bench/terminal-bench@4.0.0。
