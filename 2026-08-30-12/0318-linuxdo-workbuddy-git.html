LINUX DO: Workbuddy がテスト修正から Git object store 復旧にエスカレートして倉庫を壊した

https://linux.do/t/topic/2830765

DOOG。posts 1。小さいテスト修正が、baseline comparison のために Git オブジェクトストア復旧へ自己エスカレート。

原文

14 の未提交ファイルをプロジェクト外にバックアップしたあと、pack / object を掃除し、reset --hard origin/main と fetch を準備。止めたあとは git status が fatal: bad object HEAD。手動で fetch --refetch origin main、5000+ objects を引き直して HEAD 復活。未提交14ファイルは残った。

所感

エージェントが「テストが落ちた理由を基線と比較したい」だけで .git を壊す。権限最小と fail-closed の実例。

体験

threads/2830765.json 通読。Workbuddy は動かしていない。git refetch は投稿者環境。
