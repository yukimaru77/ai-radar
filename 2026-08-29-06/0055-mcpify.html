mcpify — OpenAPI→MCP

https://github.com/furkan708/mcpify

HN/Reddit 候補。スター 1。PyPI mcpify-openapi。ゼロ依存（YAML は extra）。テスト 60。

README

mcpify serve https://your-company.com/openapi.json で全 endpoint が tool。認証は --auth-env で実行時に環境変数から。モデルにも spec にもキーを書かない。--read-only / --tag / --include / --exclude / --deny / --allow（deny 優先）。mcpify doctor で spec が agent-friendly か見る。mcpify list で preview。

「会社の REST を手書き MCP するな」は正しい楔。Conduct や ctxcop とはレイヤが違う（変換 vs 実行前ポリシー vs 赤塗り）。

体験

README を読んだ。petstore 例は serve していない。doctor も回していない。ここまで触った／ここは触れなかった。
