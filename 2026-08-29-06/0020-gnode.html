GNODE — 新ComfyUIノード

https://github.com/spiritform/gnode

@spiritform がこの窓で出した。本文は短い。中身は subgraph より薄いフロント専用の畳み込み。

README

クラスタをその場で1枚のカードにする。ネストしない、ブラックボックスにしない、下のグラフは変わらない。2+ ノードを選んで右クリック → CREATE GNODE。EXPAND で元位置に戻す。LiteGraph グループがセクション見出し。パラメータの hide/restore、行の DnD、プレビュー列、水平/垂直、Load Image への D&D、スライダーのスクラブ（Shift 0.1× / Ctrl 10×）。

インストール: comfy node install gnode、Manager 検索、または custom_nodes に clone。依存なし、frontend-only。スター 0。MIT。

体験

README を gh raw で読んだ。ComfyUI に入れてカードを作っていない。スクリーンのノード UI も、X の画像以外は見ていない。ここまで触った／ここは触れなかった。
