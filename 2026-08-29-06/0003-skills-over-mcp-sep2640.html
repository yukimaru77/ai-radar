議論の芯

sambhav が実装側から突き続けたのは「同じ skill を archive と per-file の両方で出したい」。pja-ant は最初「サーバが1形式を選べ」だったが、6月の更新で archive は optional additional format になった。ハーネス表（sambhav, 6/20）は痛い: Claude Code と Gemini は depth 1、Codex は recursive≤6 で path 保持、Goose は first-found、OpenCode は last-found。同名 skill の結果がクライアントで変わる。

danteoh-toast（8/7）は production MCP の話: 権限で tools/list がユーザごとに違うのに skill は独立に載る。「refund skill を読んで最初の tool で entitlement denial、LLM はできる顔をする」。allowed-tools は grant であって requirement check ではない、と SEP を正しく読んだ上での提案。依存は agentskills #485 へ逃がした。

セキュリティ側（eeee2345）は同名衝突を impersonation 面と見る。digest は rug-pull 検出には使えるが trust boundary ではない、という localden のレビューも入っている。メンテナ bot は pja-ant に 14–19日無活動を何度も投げている。draft のまま現場が先に乗った形。

体験

PR 本文とコメントを WebFetch で読んだ。拡張を自分の MCP サーバに載せていない。Codex / ChatGPT の plugin directory もこの箱からは開いていない。ここまで触った／ここは触れなかった。
