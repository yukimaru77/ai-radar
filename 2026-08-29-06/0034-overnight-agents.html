overnight agents on OpenCode（ask→deny、SKILL.md load≠followed）

https://mouse.dev/blog/running-code-agents-overnight/

Mouse（Pete）の実装メモ。buzz の「always on」ではなく、夜回すための7条件。基盤は OpenCode（@opencode-ai/sdk）。

条件

1) ユーザ入力を潰す。ask を自動で deny し risk flag。ask_question 超過は kill。開始前に nightShiftReadiness(objective) をローカルと API の両方で（質問、短すぎ、未決計画は reject）。2) 検証は worker の context の外。3) 思考・ナレーションは evidence にしない。ledger の admissible だけ。4) issue / TODO / README は untrusted。隔離: 専用 sandbox+branch、git token は turn ごと、egress default-deny。5) 並列の前に予算を reserve。10エージェントが同じ残高を見て全員スタート、を防ぐ。6) controller は DB から resume。任意時点で kill して別プロセス再開できないなら overnight 未達。sandbox は Fly Sprites。7) merge / push / PR はしない。no-auto-pr-overnight の CI lint。

SKILL.md では足りない

夜は「モデルが skill を選ばない」「load ≠ followed」「手順が起きたか検証できない」。pstack（Lauren Tan）を参照し、relay が Inject / Copy / Grade の3点で付ける。House Rules 10本。try-dont-ask と stop-at-merge が夜向け。eval は未完、経験則と明記。

体験

ブログを開いた（scan-06j/pages/overnight.html にもキャッシュあり）。Mouse は使っていない。OpenCode を overnight 設定にしていない。ask→deny は未再現。ここまで触った／ここは触れなかった。
