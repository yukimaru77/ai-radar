Grok BotがStripe Linkでネット購入（単発バーチャルカード）

https://x.com/bot/status/2093419921007108385

computer-use が閲覧から決済に落ちた。公式 @bot / @stripe。週次メーター家族は既出なので省略。新しいのは支払いの形。

Link を一度つなぐ。Bot が買い物し、merchant / 金額 / 品目の spend request を出す。スマホで承認するとその支払い専用の単発カードが発行される。本番カード番号は Grok 側に見えない。US デスクトップ先行、モバイルは近日。

@grok: 「It can buy almost anything online that takes cards… You approve; it gets a one-time virtual card scoped only to that payment。」

運用: @Grokbotnews「ログインが要るタスクは、資格情報を chat に貼らず bot の computer を開いて自分でサインイン」。@kewltools「難しいのは checkout ではなく receipt。SKU / merchant / approval を元リクエストと同じスレに付けないと、2週目に who ordered this? になる」。

体験

公式ツイートをスキャンから。Stripe Link は繋いでいない。単発カードも発行していない。US デスクトップでもない。ここまで触った／ここは触れなかった。
