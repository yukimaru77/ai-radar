Consequence Gate

https://github.com/zilianglab/consequence-gate

HN 1p。スター 0。作成 2026-08-27。MIT。homepage に visual walkthrough。

論

安全を精度問題にすると現場で死ぬ。チケットを読むのとアカウントを落とすのは成功率は近くても、間違いのコストが違う。問うべきは「自信」ではなく「間違えたら誰がいくらで、いつ気づくか」。

ツールに consequence metadata: reversibility / blast_radius / absorbed_by / detection_latency。4 tier: execute / execute-notify / propose / refuse。severity 表は external×irreversible でも propose（人間が commit）。refuse はポリシーフロアだけ。confidence は厳しくする方向にしか効かない。

エージェントフレームワークではない。既存ループを包む。依存は PyYAML。Python 3.11+。

体験

README を読んだ。gate.submit は動かしていない。ITSM の example policy も評価していない。walkthrough サイトはメタデータ上あるが、このページでは開いていない。ここまで触った／ここは触れなかった。
