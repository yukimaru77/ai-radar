Blender Gaussian splat: プロキシリグ+リアルタイムrelight（KIRI無料）

https://x.com/RadianceFields/status/2093412898395537478

LichtFeld / ArtSplat 既出の続きではなく、DCC 側の操作レイヤ。@RadianceFields + @KIRI_Engine_App の無料プラグイン。

実体は Kiri-Innovation/3dgs-render-blender-addon（GitHub スター 1160、別ページ）。Radiance Fields 記事（2026、3DGS Render 5.0）によると、プロキシメッシュのアニメを splat に転送（Mixamo / mocap）。実験的で、フルシーンより小さいスキャン向き。本番寄りの追加は 4DGS（.ply シーケンス書き出し → SuperSplat）。Blender 5.1 で壊れた互換を直し、100+ issue を閉じた、とある。Superhive でも $0。

スマホ撮影スプラットを Blender 内でリグってライティングする方向。ネイティブ gsplat IO はまだ design task、と記事は書く。

体験

X と Radiance Fields 記事と GitHub リポページを開いた。Blender にアドオンを入れてリグってはいない。巨大 zip（リリース資産が 700MB 級）も落としていない。ここまで触った／ここは触れなかった。
