cairn-spec/cairn（3DGS captions関連）

https://github.com/cairn-spec/cairn

Atlanta ツアーの caption ランタイム。スター 1。作成 2026-08-15、push はこの窓の日。MIT。

アイデア

映像字幕は1本の時計を仮定する。歩けるシーンには時計が無い。Cairn は空間層（zone が fragment を発火）、時間層（fragment 内は普通の WebVTT）、状態層（一度きり、同時一声、transcript）。テキストが主、音声は enhancement。ミュートでも完結。

npm install cairn-spec。コアは engine-agnostic（clock() と bearing()）。作者付けは cairn_align.py（script + Whisper → VTT）。テスト: core 30 + visit-memory 3 + host 7 + authoring 58。v0.2 RC。PlayCanvas sound-slot adapter は実験的。本番ホストは HTML Audio 1本。WebXR と多言語 manifest は未。

体験
