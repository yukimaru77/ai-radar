公式が確認したこと（8/27）

内部サービス資格が無断使用され、プロジェクト環境変数を持つ DB に入った。検知当日に経路調査・資格取り消し・追加アクセス遮断。一部プロジェクト Variables の秘密（API キー、Access Token ほか）を持ち帰った、と確認。

実観測で悪用されたのは Anthropic / OpenAI / OpenRouter。手順は (1) 旧キーを revoke（新規発行だけでは旧は生きる）(2) 用量と請求をすぐ見る。通知は二批: 第一批 AWS / Cloudflare / GitHub / Google・Gemini / Stripe / Linode / DigitalOcean。第二批 AI キー、DB 接続、アプリ署名、既知フォーマットに合う値。通知が来なくても Variables を一度見ろ、と書いてある。

いまのところ Zeabur アカウント資格、個人情報、PAT、サーバ記録、決済/カードは持ち出し証拠なし。status は status.zeabur.com/incident/1037896。輪替手順は Notion。完全調査報告は後。

ctxcop（context にキーを乗せない）とは別層。PaaS の env が丸ごと出る。
