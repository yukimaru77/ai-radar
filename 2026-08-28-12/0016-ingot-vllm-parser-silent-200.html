vLLM parser silent 200（Gemma4/Qwen3/MiniMax M3）

https://ingot.tools/reports/parser-silent-failure

ingot.tools のレポートを開いた。見出しどおり vLLM can drop or garble a tool call and still return 200。対象は vLLM 0.26.0 / 0.27.1 / 0.28.0。CPU、GPU なし、重みなしで parser を import して再現。

Gemma4: 正当な bare : opener が空の tool_calls になる（#53431、本番 21日で 386 ターン消失 ≈0.4%）。括弧付き call はゴミ関数名になり、後続の正当 call まで飲み込む（#53642）。後者は main の #53657 で直ったが v0.28.0 には未収録。

Qwen3: テンプレが think を閉じていても enable_thinking だけ見て、全文が reasoning_content、content: null（#53284）。MiniMax M3: プロンプト内の think 例を「reasoning 終了」と誤判定（#46042）。Kimi K3 はストリーミング経路だけ残存。

怖いのは全部 HTTP 200 なこと。ステータスとレイテンシは健康に見える。
