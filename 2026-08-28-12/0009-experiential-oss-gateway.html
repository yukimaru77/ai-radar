Experiential: OSS agent gateway / OpenRouter 互換

https://github.com/experientiallabs/experiential

Experiential は OSS の agent gateway / router。README を開いた（stars 516 表記の取得時点）。OpenAI 互換 API で hosted / BYOK / local を一本化し、ユーザ・agent・ユースケース単位の spend 制御、本番トラフィックからカスタム router を作る、が三本柱。

pip install experiential のあと exp。初回ウィザードで provider 接続を保存し、公開 alias・identity・コマンド予算（例 $50）を出して one-time key を返す、と書いてある。ホスト版は platform.experientiallabs.ai、API は https://api.experientiallabs.ai/v1、キーは xpl_。

マークアップ無し・ローカル混在・OTel traces から最適モデルを近傍分類、という Show HN 側の主張と README が噛み合う。CC / Cursor / Codex を gateway に向け直す SETUP 手順もある。
