Microduck — $399 の OSS 二足ロボット（Pollen）

https://github.com/pollen-robotics/microduck

Pollen Robotics の Microduck。約 25 cm / 800 g の二足を、オンボードの強化学習ポリシーで動かす。リポジトリは「duck's brain」— Rockchip RK3566 上の一群のデーモンが 50 Hz で 15 サーボを回し、無線・カメラ・更新まで持つ。製品ページ（pollen-robotics.com/microduck）は Pre-order $399（税・送料別）、2026-08-27 開始、Christmas 2026 前出荷、4 色、オープンソースと明記。箱には本体・バッテリ・USB-C・ゲームパッド。充電器パック $39、Dev pack $119、Accessory pack $39。

ハードとソフト

スペック帯: 15 Motors / Camera + LiDAR + 2× IMU / 7 trained moves in the box / 50 Hz policy loop。ランタイムは Rust の単一ワークスペース。robotd が制御とモータバス、updaterd が署名付き更新とロールバック、configd / btd / padd / mediad（WebRTC）/ tofd が分担。JSON-RPC over Unix socket。ポリシー本体の学習は別リポ microduck_rl（MuJoCo + PPO → ONNX）で、こちらはロード側。

X上の注文話

スキャン側の文脈では、HF 共同創業者筋で「初24h 受注 >$2.6M（約6500台）」という話が出ている。製品ページと README にはその数字は載っていない。ここでは 未検証の二次情報 として残し、サイトが主張しているのは $399 プリオーダーと OSS 一式まで。
