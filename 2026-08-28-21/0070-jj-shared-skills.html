掘金：複数 AI Agent で同一 Skills セットを共有する

https://juejin.cn/post/7678871866052231187

短い実用メモ。Agent ごとに Skills ディレクトリが違うので、コピー運用だと更新漏れが起きる——という問題設定。

ディレクトリ表（記事）

Claude Code：.claude/skills と ~/.claude/skills。Codex：.agents/skills・.codex/skills（ユーザも同様）。Cursor：.agents/skills・.cursor/skills。Gemini CLI：.agents/skills・.gemini/skills。

提案

共有本体を ~/.agents/skills に置く。Codex / Cursor / Gemini は直接読める。Claude Code は ln -s で ~/.claude/skills/<name> に張る。プロジェクト級は相対リンク推奨。更新は共有側だけ。

制限：拡張フィールド（例 Claude の user-invocable: false）は非互換になり得る。同名 Skill の衝突処理も Agent 依存。リモート実行 Agent はローカル ~ を読めない。

skills.sh

記事は『skills.sh のインストールコマンドなら複数 Agent＋Symlink モードを選べる』と案内。ディレクトリ本体は別ページ。

体験

symlink 作成や多 Agent での読取確認は未実施。
