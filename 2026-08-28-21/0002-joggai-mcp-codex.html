JoggAI 公式 MCP → Codex（OAuth・ホスト型）

https://docs.jogg.ai/mcp/codex

動画生成の JoggAI が、ホスト型 MCP を Codex に公式接続する手順を公開した。ローカル MCP サーバも GitHub clone も不要。推奨は npx -y @joggai/mcp-client install codex で OAuth クライアント設定ごと入れ、ブラウザで Space 認可まで流す。

ドキュメントの手順

エンドポイントは docs の手動セットアップでは https://api.jogg.ai/mcp。ただし npm パッケージ @joggai/mcp-client@0.1.2 の --help だとデフォルト URL は https://api-services-intl.jogg.ai/mcp。スコープ例は openid,account.read,quota.read,...video.generate,...。最初の試運転プロンプトは「残り quota と公開アバター5つを読むだけ・何も作るな」→ そのあと talking-avatar 生成、と段階を分けている。OAuth callback は Codex が選ぶ loopback を使え、カスタム HTTPS callback は拒否される、と注意書きがある。

兄弟ページとクライアント

https://docs.jogg.ai/mcp/claude-code / .../cursor / .../chatgpt / .../claude はいずれも 404。docs 上の個別 URL はいま Codex だけ。一方 npx -y @joggai/mcp-client clients は codex / claude / cursor / chatgpt を返す（claude・cursor は automatic_install=true、chatgpt は manual）。別 HTML ページは無いので、このスロットでは Codex docs のみを独立ページにした。

体験

やったこと: docs ページ全文、/llms.txt、npm view、npx -y @joggai/mcp-client --help と clients。https://api.jogg.ai/mcp は GET/POST とも 404。https://api-services-intl.jogg.ai/mcp は GET/POST とも 401（invalid_token / authentication required）— 公開で叩けるが未認証。

やらなかったこと: install codex の実行、OAuth ログイン、動画生成、アバター一覧の実呼び出し。生成ランは捏造しない。
