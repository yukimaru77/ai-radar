GLM-5.3 vs Flash：公式2本のベンチ版を揃えると「84対28」は錯覚

https://linux.do/t/topic/2825949

Z.ai が GLM-5.3 と GLM-5.3-Flash で別々の評測図を出し、Terminal Bench の版が 2.1 と 3.0 で食い違っている——そのまま並べると Flash 84 対 本体 28 みたいな偽ギャップが見える。LINUX DO 2825949（『GLM-5.3-Flash 我要打十个』）は、公式2本の生データを 同じ基準に揃えた表を貼った1本勝負の議論帖。

揃え後の数字（投稿＋RSSの表のみ）

投稿者が抽出・整列した値（参照として Kimi K3 / GPT-5.6 Sol / DeepSeek-V4 Pro-0813 も並ぶ）。こちらで再計測していない。

Terminal Bench 2.1：本体 88.2 / Flash 84.3（Sol 88.8 が行内最高付近）。

Terminal Bench 3.0：本体 28.3 / Flash 未公表（–）。3.0 は難度が跳ねる——投稿注記では GLM-5.2 が 2.1 で 81.0 → 3.0 で 4.6。本体 28.3 は開源 SOTA 主張。

Toolathlon Verified：Flash 78.4 が本体 73 を上回る（表上 Flash が行内最良）。

AutomationBench v1.0.6：Flash 48.8 ≒ 本体 48.2。

DeepSWE v1.1：本体 66.9 / Flash 63.4。NL2Repo：58 / 56.3。Agents’ Last Exam (CLI)：28.5 / 26.3。HLE w/ Tools：62.5 / 55.3。GDPval-AA v2 Elo：本体 1769 / Flash 1773（Flash がわずかに上）。

Flash 列が空（–）の項目も多い：SWE-Marathon、PostTrainBench、CyberGym、ExploitGym、ExploitBench など。空欄をゼロ扱いしないのがこの帖の本筋。

論点

比較広告の落とし穴はスコアそのものより ベンチ版のラベル。TB 2.1 の 84 と TB 3.0 の 28 を『Flash vs 本体』と読むと物語が壊れる。データ源は投稿者表記どおり Z.ai 公式ブログ2本と tbench.ai。

2帖目は『表では3項目で首位なのに、行列の左下要素を最初に書き間違えて数学が全部崩れた』という現場感想——ベンチと体感の乖離ネタ。

体験

公式ブログ原図の再スクレイプ、tbench.ai の再集計、自前の Terminal Bench 実行はしていない。数字は スレ本文＋RSS 抜粋の範囲に閉じた。
