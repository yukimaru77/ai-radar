ComfyUI-Trellis2-AMD: ROCm 10 + AuleAttention（検証は6800 XT）

https://github.com/dmonkman/ComfyUI-Trellis2-AMD

Redditから辿ったフォーク。Changelog: 2026-08-26 に AMD/ROCm と AuleAttention、2026-08-22 にフォーク作成。

ハード

E2E検証は Radeon RX 6800 XT (gfx1030, RDNA2)、Windows 11 と Ubuntu 24.04（22.04は動かない）、Python 3.12、ROCm 10.0.0、PyTorch 2.13。ホイールはRDNA1–4とgfx1250のfat multi-arch。表のカードはgfxが入っている、という意味でパイプライン検証ではない。dinov3-vitl16 を HFから models/facebook/... へ。Pixal3D-T には natten。Python 3.13+ は Windows で open3d 等が死ぬ。

インストールはクリーンvenv必須（既存CUDA PyTorchがROCmを静かに壊す）。pip install --extra-index-url https://stable.repo.amd.com/rocm/whl-next/ で torch==2.13.0+rocm10.0.0 系。device-all か device-gfx1030。

体験

README（約10.8KB）を開いた。ROCmホイールは入れてない。6800 XTも無い。dinov3もTRELLIS.2も未実行。ComfyUIカスタムノードとしてのloadもしていない。
