T3rnel Browser: ログイン済みタブをエージェントに渡す拡張（98 tools）

https://t3ratech.github.io/t3rnel-browser-plugin/

mcp-session-bridge READMEが「ここを入れろ」と指す本体。サイトコピーは DevTools you can talk to。Version 1.1.1 · 98 tools · no servers。Chrome / Brave は即インストール、Edge / Opera / Firefox は in review。Chromium用パッケージは同じ。

moatの主張

Chrome DevTools MCP、Playwright MCP、mcp-chrome、Browser Use は無料で強い。「自動化レイヤでは勝てない」。moatは human loop: 資格情報をモデルに渡す前にredact、ページを変える操作は止まって聞く、タイムラインを巻き戻せる。実ブラウザ・実セッションで、別自動化ブラウザへの再ログインも自動化フラグもなし、と書く。

無料帯は永久に使える、Proは $29.99 once / 3 activations / サブスクなし。機能リストはCSS検査、フルページスクショ（sticky header対応）、Markdownビューア、a11y/スペル/リンク監査、record→CI用テストexport、暗号化identity vault、カラーピッカー、React tree、フォーム充填。

体験

ランディングHTML（約13KB）を開いた。Chrome Web Storeへの実インストールはしていない。拡張をこの箱のブラウザに入れてMCPからタブ操作もしていない。価格とツール数はサイト文言のまま。
