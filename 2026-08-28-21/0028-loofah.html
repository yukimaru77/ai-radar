Loofah: ローカル文字起こしをMarkdown vaultに落とす（macOS）

https://github.com/bart6114/loofah

Show HN（id=49477356、2 points / コメント0）。「meeting transcription into a local Markdown vault」。ベースは [anarlog](https://github.com/fastrepl/anarlog)。アカウント・課金・テレメトリ・プレミアムなし。ノートは普通のMarkdownで、アプリ無しでも読める。要約AIは任意の持ち込み（OpenAI / Anthropic / Gemini / OpenRouter / Ollama / LM Studio / 互換）。

中身

配布は署名・公証済み Apple Silicon .dmg（releasesの Loofah_latest_aarch64.dmg）。会議に参加してMac上で録音・文字起こし、vaultへ保存。CLI loof とMCPサーバで、スクリプトやコーディングエージェントに read-only でノートを渡せる。モノレポは pnpm workspace、デスクトップは Tauri（apps/desktop/）、CLIはRust（apps/cli/）。DBなし。vault形式は crates/vault-read/。UIは Zustand + TipTap。MIT（anarlogのcopyright履歴込み）。

体験

README（約3.3KB）を開いた。この箱はLinuxで、Apple Silicon dmgは使えない。pnpm install も pnpm -F @hypr/desktop tauri:dev も cargo build -p loof-cli もしていない（デスクトップは重い）。実会議の文字起こし、MCPからの読み出し、Ollama接続は未実施。軽量ではなかったのでREADMEと正直な未実施で止めている。
