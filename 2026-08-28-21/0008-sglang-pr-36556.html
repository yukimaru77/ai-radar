SGLang PR #36556 — QSA sparse decode を SM120/SM121 で通す

https://github.com/sgl-project/sglang/pull/36556

poorpaper の stacked fix（ベースは #36497 系 qwen4-main-squashed）。問題: SM120 で _resolve_trtllm_sparse_decode() がアーキを弾き、pip の flash_attn.cute.interface に落ちて QSA packed varlen warmup が死ぬ（共有メモリ要求 131072 > GPU 許容量 101376 の CUDADialectError 例あり）。

直し方

FlashInfer TRTLLM sparse-decode を SM120 と SM121 で有効化。FlashInfer が無い major-12 は SGLang 所有の FA4 dispatcher へ。非 SM12x は従来の FA2-first 順を維持。Fixes #36531 / #36558。

検証

RTX 5090 (SM120) で TRTLLM 経路が PyTorch 参照と max_abs_diff 7.18e-4、CUDA Graph replay OK。コミュニティ検証で SM121（GB10 / 2× DGX Spark TP=2） も TRTLLM max_abs_diff 4.70e-4、Qwen3.8-Flash-Next が NEXTN decode graph を撮って end-to-end サーブ、とコメント。著者機 32 GiB ではフルサーバ未起動・カーネル形状での検証、と正直に書いてある。

体験

PR HTML を開いただけ。ローカルカーネル再現はしていない。
