非公式 Grok Bot Linux AppImage 0.29.0 — 公式Linuxまだ無し

https://github.com/glorics/grok-bot-linux/releases/tag/v0.29.0

公式の Linux デスクトップが未だ無い穴を、コミュニティが塞ぎ続けている。glorics/grok-bot-linux の v0.29.0 が出た。直前の既知は 0.28.1。リリース本文ははっきり「Unofficial」「Not an xAI or Cursor release」と書く。素材は公式 Windows インストーラ Grok_Bot_0.29.0_Setup.exe をバラして Linux Electron に載せ替え、Windows 専用 native を差し替えたもの。

中身と対応ディストロ

README（raw）上の一次テストホストは Debian 12 Bookworm（amd64 / glibc 2.36 / GNOME・Wayland）。AppImage は generic linux-x64 / glibc（musl・ARM ではない）。glibc ≥ 2.34 が必要。Arch と Linux Mint はコミュニティ確認済み（X上の報告リンク付き）。Fedora は「未検証」だが glibc は新しいので動く想定、失敗点はだいたい FUSE2。Electron はリリースノートで 42.1.0。0.28.1 の Linux デスクトップ identity（Plasma アイコン等）は引き継ぎ、既存 GNOME dock の Exec は書き換えない、と明記。

配布物と起動

アセットは少なくとも Grok_Bot_0.29.0_x86_64.AppImage と Grok_Bot_0.29.0_linux_x64.tar.gz。HEAD で測ったサイズは AppImage 119,900,664 bytes（約114.3 MiB）、tar.gz 129,051,525 bytes（約123.1 MiB）。起動は chmod +x のあと ./Grok_Bot_0.29.0_x86_64.AppImage --no-sandbox。--no-sandbox 必須（AppImage に Chromium setuid sandbox を同梱できないため）。scripts/install-linux.sh で XDG ランチャと ~/.local/bin/grok-bot を入れられ、起動時に GitHub 最新を見て SHA-256 / ELF 検証してから差し替える仕組み。0.28.1 は公開のまま残す、とも書いてある。

体験

やったこと: リリースページと README raw を開いた。AppImage URL に HEAD して Content-Length を確認。Range 0-15 で先頭16バイトを取り、ELF magic 7f 45 4c 46 を確認（フルダウンロードはしていない）。GitHub API はこの箱から rate limit で JSON が取れず、HTML + raw に依存。

やらなかったこと: AppImage 全体の DL、GUI 起動、インストール、ログイン、FUSE マウント試験。箱にディスプレイ付きで Grok Bot を立てる意図もない。公式 Linux が来るまでのブリッジとして「ある」、という事実確認まで。
