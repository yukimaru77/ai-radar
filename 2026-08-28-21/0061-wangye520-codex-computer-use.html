ハイライト（README 記載）

ゼロインストール志向の PowerShell + .NET スクリプト cua.ps1（Python/pip 不要）。モニタ別 DPI 対応でスクショ座標＝クリック座標。アクション一式：screenshot / click / move / type / paste / key / scroll / drag ほか find-window 等。常駐 server モードで 1アクション約 30–100ms（都度起動の ~0.8s を回避）。青い AI カーソルは click-through・最前面、スクショ時は自動非表示。
