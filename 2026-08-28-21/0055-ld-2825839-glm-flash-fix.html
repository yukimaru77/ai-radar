智谱、GLM-5.3-Flash の「降智」を公式飛書で修復告知

https://linux.do/t/topic/2825839

朝から中国圏で鳴っていた GLM-5.3-Flash Coding Plan 降智クラスタに、公式側の返事が来た。LINUX DO 2825839（ニュース系、topic.json 取得時点で 6帖 / 376 views）。タイトルは『智谱修复glm5.3-flash模型能力下降问题』。

ソースの読み方

本文はスクショ1枚＋短レス。メッセージ源は公式飛書群と明記されている。topic.json は通常 UA の curl で取れた（一部他トピックは直後に 429）。返信スレの中身は飛書通知のスクショ本体までは OCR していないので、修復の技術詳細（どのエンドポイント／どのルーティングを直したか）はここからは確定できない。

スレの空気

2帖目は『飛書に通知がポップした瞬間、もう帖が立っていた』という速さ自慢。3〜5帖は皮肉の連鎖で、GLM-5.3 Flash が設定を取り違えた／DeepSeek V4 Pro 0813 がモデル取り違え／以前は Qwen3.8 Max が別モデルに乗った、といった“草台班子（寄せ集め現場）”ネタ。6帖目は『ユーザーが圧をかけて算力の粗を突くから公式も休めない』というジョーク。

つまりこの帖の価値はベンチ数字ではなく、朝の降智報告に対する公式チャネルの一次レスポンスが飛書経由で出たという事実そのもの。

体験

こちらから智譜 API や Coding Plan を叩いて before/after を測ってはいない。降智が直ったかは、自分の glm-5.3-flash 呼び出しでレイテンシと回答品質を再確認するしかない。公式飛書群への参加も未実施。
