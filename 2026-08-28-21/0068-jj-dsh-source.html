掘金：dsh を分解——Git 歴史と npm から見る DeepSeek Harness の境界

https://juejin.cn/post/7678969473362673690

DeepSeek Harness（dsh）公開は約2週間でも、中身は約2ヶ月の内製。分析は deepseek-ai/deepseek-harness の Git 全歴史と npm 上 227個の @deepseek-ai/dsh-*、截止 0.1.1-rc.2 / commit b150a551b8。

数字

初 commit 2026-06-10。0.1.1-rc.2 時点で 13,147 commits / 44 contributors。monorepo packages/<domain>/<package>、公開可能包 227＋apps/cli・apps/web。初 rc は 2026-08-11（その時点で既に 214 包）。W31 は週 3,575 commits。

位置づけの書き換え

README が *open-source coding agent built on the DeepSeek Harness SDK* から *open-source agent harness developed by DeepSeek AI* へ。npx @deepseek-ai/dsh web が主入口、遥測は opt-in、コミュニティは GitHub Discussions / Discord / dsh-plugin topic。

rc で見えた境界操作

rc.3 の大規模リネーム（bash→shell、pty→terminal、tasks→jobs 等）は alias 非互換の契約整理。rc.7–8 で Codex / Claude Code を 個別 Bundle に外出し、Agent Teams は packages/experimental/（安定 Release から隔離）。0.1.1 で Credential Record / Authorization Flow / OAuth、続く画像マルチモーダルの配管。

体験

記事の追検証として GitHub README と docs サイトは開いた（別ページ）。npx @deepseek-ai/dsh web の起動や内部 .agents/notes/ 559本の通読は未実施。
