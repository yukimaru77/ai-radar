JetBrains go-modern-guidelines: エージェントに現代Goを書かせるスキル

https://github.com/JetBrains/go-modern-guidelines

HN（id=49476502、3 points）。公式JetBrainsリポ。エージェントが古いGoを出す理由を2つに割る。(1) 学習データの遅れ — cutoff後の errors.AsType[T]（Go 1.26）を知らない。(2) 頻度バイアス — for i := 0; i < n; i++ の方が for i := range n より多い。ガイドラインは Go 1.0〜1.27、modernize アナライザが狙う範囲をカバーする。エージェントは go.mod からバージョンを読み、そこまで使える機能だけ使う。

SKILL.md が強制すること

実体は plugin/skills/use-modern-go/SKILL.md。Goを書く・直す・リファクタするとき 必ず Modern Go Guidelines CLI を呼べ、が契約。ラッパは Linux/macOS で sh "<skill-dir>/scripts/run-tool.sh"。初回はローカルキャッシュへCLIを入れる。サブコマンドは list と explain。編集前に対象ファイルで list --file-path path/to/file.go。出力は新しい順。head/tail/grep/sed で切るな（古いガイドラインが落ちる）。該当するならリポの古い慣習よりガイドラインを優先。スキップはコンパイルできない・挙動が変わる・明らかに無関係、のときだけ。その前に explain <id>。

READMEの具体例: max(a,b) をifの代わりに、slices.Contains、cmp.Or、new(42) で値のポインタ、errors.AsType[T]。

入れ方

Junie / Claude Code / Codex / Cursor は marketplace。Claudeは /plugin marketplace add JetBrains/go-modern-guidelines → /plugin install modern-go-guidelines@goland-claude-marketplace。明示呼び出しは /modern-go-guidelines:use-modern-go。Codexは codex plugin marketplace add ... → codex plugin add modern-go-guidelines@goland-codex-marketplace。他エージェントは npx skills add JetBrains/go-modern-guidelines。CLI自体は go install、Go 1.25+（古いGoは GOTOOLCHAIN=auto）。キャッシュは ~/.cache/go-modern-guidelines。プロジェクトは改変しない。

体験

READMEとSKILL.mdを raw で開いた。GoLandでは動かしていない。Junie/Claude/Codex/Cursor にプラグイン追加もしていない。npx skills add も、go install も、list / explain の実出力も未取得。この箱でGoコードを現代化した事実はない。
