SGLang PR #36567 — Qwen3.8-Flash-Next の PLE を NVMe ストリーム

https://github.com/sgl-project/sglang/pull/36567

jzinno の feat(qwen4): stream PLE embeddings from NVMe。スタックは #36497（Qwen 3.8 Flash Next 導入）の qwen4-main-squashed 上。動機: Qwen3.8 Flash Next NVFP4 チェックポイントに 47.68 GiB の FP8 PLE n-gram embedding があり、128 GiB 級 unified memory（DGX Spark 等）で常駐させるとモデル本体・Mamba・KV が窮屈。PLE は forward ごとに少数行しか使わないので、シャード safetensors を NVMe に残して必要行だけ読む。

実装の骨

Linux Rust 拡張 + 永続 io_uring、page-aligned、GIL-free。mmap / io_uring 行リーダ、ピン留め staging、非同期 H2D、デコーダ層とのオーバーラップ。初期パスは TP1・FP8 E4M3 のみ。opt-in 環境変数 SGLANG_QWEN4_PLE_NVME_PATH。SM121 向けに Triton sparse GQA decode fallback も追加（TRT-LLM sparse が無いとき）。行一致テストは RadixArk/Qwen3.8-Flash-Next-NVFP4 rev 7b71922… で byte-exact。
