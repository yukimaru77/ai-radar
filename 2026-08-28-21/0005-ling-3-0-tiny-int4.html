Ling-3.0-tiny-int4 — 5.4GB級 INT4、4060 Laptop 報告つき

https://huggingface.co/inclusionAI/Ling-3.0-tiny-int4

inclusionAI の Ling-3.0-tiny INT4（compressed-tensors / pack-quantized）。総パラ 7.9B、活性 1.3B/token。KDA×3 + MLA×1 のハイブリッド線形注意と、128 expert MoE（8 routed + 1 shared）。カード上の model.safetensors.index.json metadata total_size = 5,805,705,224（約 5.41 GiB）。HF usedStorage 約 5.42 GiB。X 報告の「weights 5.54GB」と同オーダー。MIT。

公式が言っている環境

README は BF16/FP8/INT4 を出し、検証例として DGX Spark / Apple Silicon を挙げる。FP8 で DGX Spark 約100–105 tok/s、M4 Pro 86–90 tok/s、8K 文脈で peak mem 約 8.34 GiB。起動は SGLang cookbook / lmsysorg/sglang:dev-Ling-3.0-tiny イメージ。関連の公式サポート PR は sgl-project/sglang#33561（Hopper/Blackwell 向け INT4=Marlin on H200 等）。

Xコミュニティ報告（未検証）

スキャン文脈: RTX 4060 Laptop 8GB、KV ~6.8KB/token、74k needle 15/15、decode median ~27 tok/s。公式ターゲットは SM90/100 寄りの話が多く、4060 は sm_89。Marlin は sm_80+ なので「unsupported だが動く」系の報告、という位置づけ。こちらでは再現していない。

体験

やったこと: モデルカード README、HF API、config.json、model.safetensors.index.json を取得。アーキは BailingMoeV3ForCausalLM / bailing_hybrid、num_experts=128、num_experts_per_tok=8、量子化は group_size 32 の INT4。

やらなかったこと: 5.5GB 級ウェイトのダウンロードとロード。VRAM も時間も食うので未実施。ベンチ数字はカードと X 報告の引用のみ。
