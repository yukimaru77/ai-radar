掘金：Codex で前端 Skill 3本を実測（taste / humanizer / better-interface）

https://juejin.cn/post/7678969473362821146

著者『小七』の実測記事（全文 mark_content）。環境は Windows / Codex CLI 0.149.1 / GPT-5.6 Sol High / HTML+CSS+JS、架空プロフィール vic-source.md、Skill はすべて Project の .agents/skills/ のみ。

流れ

Baseline（サードパーティ Skill なし）でも黒地＋蛍光黄緑の個人ページを作り、ブラウザで桌面／移動端を自己検査して CSS 修正——『土味→変身』の台本が最初から不要になった。問いは 既に出来る Agent に Skill を重ねると何が増えるか。

3 Skill

design-taste-frontend（npx skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend）：双テーマのコンポーネント寄り、画像内焼き込みテキストを HTML テキストへ分離、390/500px や prefers-reduced-motion など QA が厚い。ただし Taste 版は画像生成も使っており、差分を全部 Skill に帰せないと著者自身が釘を刺す。

humanizer（npx skills add https://github.com/blader/humanizer）：レイアウト固定で文案だけ。例『在城市之间，做产品，也做记录』→『在不同城市生活，做产品，也拍照』。インストール時 Snyk High Risk 表示→SKILL.md を人手確認してから Project 限定で続行、と安全メモあり。

better-interface（jakubkrehel/skills から better-interface ほか accessibility/layout/writing/typography/colors/ui の7本）：まず Review only で A4/B4/C0、Verdict Block。A1–A4（コントラスト、フォーカスリング、accessible name、aria-pressed 同期）だけ直して PASS。PASS＝本 Round の A 類ゼロであり、本番 a11y 認証ではない、と明記。

体験

Codex へのログインも Skill の実行もしていない。 一次体験は著者側。こちらはリポ README と skills.sh を開いた（各別ページ）。
