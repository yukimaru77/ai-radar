pjlsergeant/byre: フォルダを囲む快適なエージェント用コンテナ

https://github.com/pjlsergeant/byre

HN「AI Agent Has Root」スレで petesergeant が二度貼った実体。「CC in a container」に TUI、再利用スキル、暗号化資格情報を足し、いつでも素の Docker/Podman に戻せる。コピーは --dangerously-skip-permissions, without risking the farm. MIT、単一Goバイナリ、Linux/macOS。

快適と拘束

byre develop がカレントを /workspace にマウントした箱を作る。テンプレは Go / Node / Python。エージェントスキルは Claude Code / Codex / Gemini / Grok / OpenCode。ログインはプロジェクト単位でリビルド後も残る。byre config はSSHでも動くキーボード駆動エディタ。GRANT（mount / port / egress / env）とBUILD（template / agent / packages / skills / MCP）を同じ語彙で触る。設定はホスト側のTOMLカスケードで、プロジェクト内からは読めない。--self-edit はエージェントに箱設定を渡す危険モード。

拘束側: ホストの他ファイル・環境・資格情報は明示GRANTなしでは見えない。ネットワークとプロジェクトツリーは意図的に開いている。「セキュリティ製品でもnannyでもない」。byre status がマウント・ネットワーク・スキル・state volを1画面に出す。生成Dockerfileは持って出して良い。

Installは brew install --cask pjlsergeant/tap/byre。要DockerまたはPodman。Linuxはchecksum付きinstall.sh / go install。若いプロジェクトなのでmaturity noteを読め、とREADMEが言う。
