ZCode（zcode.z.ai）— GLM-5.3 公式 Harness / ADE

https://zcode.z.ai/

LINUX DO の週末3億トークン告知が指していた ZCode の公式面。https://zcode.z.ai/ は /cn に着地し、タイトルは 『ZCode | GLM-5.3 官方 Harness』。別系統の zcode.zhipuai.cn はこちらから接続失敗、zcode.ai は無関係な AI Picks サイトへ飛ぶので注意。

開いて確認したこと

ランディングは『简单、迅捷、氛围十足』の ADE（Agentic Development Environment）訴求。長程タスク／Bot 制御（微信・飛書・Telegram）／GLM-5.3 深度集成、Flash のマルチモーダル（截図理解）も併記。ダウンロード表では macOS Apple Silicon / Intel v3.10.1、Linux x64/ARM64 Beta、Windows 枠あり。

料金カードは BigModel の GLM Coding Plan（Lite ¥94.4/月・Pro ¥430.4/月・Max ¥862.4/月の表示。価格は変動し得ると明記）。『ZCode・Claude Code など 20+ ツール対応』とある。

公式 docs（zcode.z.ai/cn/docs/welcome）では Goal モード、ブラウザ自動化、Wiki / Memory、闲时任务、Remote、Bot Channel、子智能体、Plugin / Skill / Command / Hooks が一覧化。智譜 docs 側 docs.bigmodel.cn/cn/coding-plan/tool/zcode では Coding Plan 向けエンドポイントとして https://open.bigmodel.cn/api/coding/paas/v4 と Anthropic 互換 https://open.bigmodel.cn/api/anthropic が案内され、限时で Coding Plan ユーザーは ZCode 内ログインで 1.5 倍额度とも書かれている。

体験

dmg/AppImage のインストール、API Key 投入、週末3億の领取、Goal モードや Bot Channel の実走は 未実施。読んだのは公式サイト・docs・Coding Plan 連携ページまで。
