OpenClaw: 分割インジェクションで 95.5%

https://x.com/0xManan/status/2093716553271476721

＠0xManan の一次。「AgentDojo-style single-shot injection is near zero on GPT-5.4 here. split it across file writes and memory updates in an OpenClaw workspace and you’re at 95.5%. nothing in any one step looks like an attack.」単発インジェクションはほぼゼロなのに、ファイル書き込みと memory 更新に分割すると 95.5%。どの1ステップも攻撃に見えない、が核心。

論文は arXiv 2605.31042（兄弟ページ 0008）。AgentDojo 系の評価が「1メッセージに毒を全部入れる」前提だと、ワークスペース型エージェントの現実を測れていない、という主張に読める。OpenClaw のように file write + memory を許可しているハーネスでは、防御側が単発フィルタだけ持っていても抜けられる。

前窓までの OpenClaw 話は機能・互換の一次が多かった。本窓の差分はセキュリティ数字が初めて出たこと。スキャン末尾の触る順も「OpenClaw ワークスペースにファイル書き込み + memory を許可しているなら、単発インジェクション対策は効いていない前提で」と書いている。

同じ時間帯に beta が壊れた一次（＠aesadde）もあるが、それは別 URL（0026）。このページは分割インジェクションの数字だけを扱う。攻撃の再現手順は書いていないし、こちらでも走らせていない。

体験

ツイート数字を x-scan で確認。攻撃は未再現。論文 abs は 0008。
