Microduck: 身体スキルが fork できる、RL 報酬が作り込まれている

https://x.com/boyang_xie/status/2093703656235586045

＠boyang_xie。24h で $2.6M+。「You’re not just buying a robot… Imagine downloading: pick-up-a-cup / follow-me / open-a-drawer like downloading a model today. Maybe the real breakthrough isn’t cheap robots. It’s making physical skills forkable.」ハードの安さより、身体スキルがモデルのように fork / 配布できること、が主張の芯。

実装スタックの一次、＠aaaaaaaaaaafedb。15モータ / ToF LiDAR / 2 IMU / RK3566 / 50Hz オンボード、Rust runtime、MuJoCo Warp、PPO、ONNX で実機。sim-to-real はバックラッシュ + domain randomization。前窓で見えていた RK3566 以外の中身がようやく並んだ。

＠masato_ka が `microduck_rl` を解析中。「報酬作り込んでますね。2速歩行ロボットの全身動作のRLの貴重な実装例」。読みとしては obs はジョイント / 頭 / 体姿勢、action は関節指令、Twist はコントローラ入力。安い二足の公開 RL が少ないので、報酬設計そのものが学習資源になる。

ロボティクス・クラスタとしては、クラウドファンディング数字（$2.6M+ / 24h）より、forkable skills というプロダクト言語と、PPO+ONNX+報酬の中身が本窓の差分。買って終わるロボットではなく、スキルを pull するロボット、という語り方がエージェント時代の延長にある。
