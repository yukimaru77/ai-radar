SkillBuddy — Skills / MCP をエージェント横断で同期

https://x.com/konnga6/status/2093714511706685804

＠konnga6（14:56 UTC）がデスクトップアプリ SkillBuddy を出した。散らばった Skills と MCP を、エージェント横断で install / sync する。対応名は Codex、Claude Code、Cursor、Kimi、ZCode。ハーネスが増えるほど「同じ skill.md を5か所にコピー」が日常になるので、同期レイヤ自体が道具になる、という打ち出し。

ツイート本文は短く、機能の芯はリポ側にある。README（v0.1.9）だと Unified inventory で各 Agent の Skills / MCP を自動発見し、1つの Skill を user / project の複数ターゲットへ一括インストール、コピー同士の drift を比較して基準から同期、enable / disable / trash+undo、skills.sh / SkillHub / GitHub からの発見、MCP の change plan プレビュー、Presets / bundles、チーム用 Git ライブラリ、まで並ぶ。紹介ポストは入口、中身の約束はここ。

前窓までの「Skills を Git に置いて Hermes + Claude + Codex が同じファイルを読む」（＠BrianFOConnor など）はファイル共有の一次解だった。SkillBuddy はそれを GUI の inventory + drift に持ち上げた。llmquota が「どのセッションに残量があるか」を読むのと対で、こちらは「どのツールに同じ Skill が入っているか」を読む。どちらもホスト型コーディネータや新規 API キーを増やさない方向。

注意点もある。対応表に OpenCode / Pi / Goose はまだ出ていない。Electron デスクトップなのでヘッドレス常駐とは別物。MCP の transport やパス検出は Agent 側のレイアウト依存で、README の Screenshots が約束している「衝突の可視化」がどこまで実機で効くかは起動してみないと分からない。
