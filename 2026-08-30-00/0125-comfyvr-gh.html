newsbubbles/ComfyUI-ComfyVR

https://github.com/newsbubbles/ComfyUI-ComfyVR

GitHub newsbubbles/ComfyUI-ComfyVR。README 冒頭:「Fly through your ComfyUI workflows.» ワークフローが暗い星座のハブになり、中に入るとグラフ深度ごとのホログラム・リング、ワイヤーは光の弧。Queue するとパルスが実ワイヤーを登り、画像が中心に形成。出力はギャラリー。GLB/OBJ/PLY は実メッシュ、.splat/.ksplat/.spz は歩ける場所。

Install は `ComfyUI/custom_nodes` に clone して再起動、`http://127.0.0.1:8188/comfyvr/` を開くだけ。ノードはゼロ登録でフロントのルートだけ。ワークフロー本体は改変せず、編集はサイドカーに保存。standalone（`python server.py` + aiohttp）と、バックエンドなしの demo mode もある。

VR: Quest 2 を wifi・ケーブルなし・開発者モードなしで検証。`python vr.py` が自前 https を出し、ヘッドセットブラウザで証明書警告を一度通せば ENTER VR。USB+adb reverse、PCVR（localhost）も文書化。手トラッキングは Quest の select イベントを流用。DICTATE は 127.0.0.1:8765 のローカル Whisper 系が必要。

Limitations（原文の見出しどおり）: サブグラフは描画されるが queue 拒否、ゼロからの新規ワークフロー作成は未実装、ギャラリーは Comfy 再起動で忘れる、カスタムノードの独自ウィジェットは汎用表示、VR 中の splat はモバイル GPU 用に間引き。Contributing は Quest 3 / Pico / Index / Vision Pro など未所持ヘッドセットでのテスト報告を最優先、と明記。
