thedotmack/claude-mem。README badge は version 13.4.0、Node >=20、Apache-2.0。キャッチは Persistent memory compression system built for Claude Code。作者 Alex Newman。0301のbrilliantroughが OpenCode 側の現行トップとして使っているリポ。

入れ方はREADME Quick Startの単コマンド。OpenCode向けは --ide opencode。Antigravity もある。Claude Code内は marketplace add thedotmack/claude-mem のあと plugin 側で入れる。再起動すると前セッションの文脈が新しいセッションに出る、とREADME。

中身（README）

Lifecycle hook が SessionStart / UserPromptSubmit / PostToolUse / Stop / SessionEnd。WorkerはBun管理のローカルHTTP。SQLiteに sessions / observations / summaries。検索は mem-search skill と Chroma の hybrid。MCPは search で index、timeline で前後、get_observations で全文。先に絞ってから詳細、で約10xのtoken節約と書いてある。

設定は ~/.claude-mem/settings.json。CLAUDE_MEM_MODE で code / code--zh / code--ja。中国語観測は code--zh が組み込み。プライバシーは private タグで保存除外。Web viewerがworker起動時URL。Claude Desktop skillもある。

0301現場との差分

brilliantroughの実測: 公式の --ide opencode は ~/.config/opencode/plugins/claude-mem.js を置き、実体は ~/.claude/plugins/cache/thedotmack/claude-mem 。このjsはsearchだけ。残りツールは bun で marketplace の plugin/scripts/mcp-server.cjs を opencode.jsonc の local MCP にする。NewAPI勢は初期化で OpenRouter を選び、jsonで BASE URL / model / API key を直す。CLAUDE_MEM_CONTEXT_OBSERVATIONS は 20。worker のフォールバックは 127.0.0.1:37700。

本人評価: 細部は強い、タスク主線は知らない。主線と規範の継続はmagic-context、人間向け文書はStrictDoc、という分担。
