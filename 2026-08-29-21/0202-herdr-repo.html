levi-qiao/herdr-agent-quota — 資格情報スコープの実クォータ

https://github.com/levi-qiao/herdr-agent-quota

Herdr のエージェント sidebar に、ペインのセッションと credential に帰属できる実クォータ／文脈だけを出す Rust プラグイン。MIT。要件: Herdr 0.8.0+、Rust 1.95+、macOS/Linux、対応 CLI が1つ以上。./install.sh。

Coverage: Claude Code 5h+7d、Codex 5h+7d（canonical ChatGPT login；API key はサブスクではない）、Grok CLI 7d、Agy 5h+7d、OpenCode は Go の 5h+7d（dashboard は 30d）、Pi は安全に一致した既存 Codex クォータのみ。

configure --apply --agent claude,codex,pi などで選択。accepted: all/claude/codex/grok/agy/opencode/pi。OpenCode Go はメンテナがサブスク未所持で実レスポンス未観測、CodexBar 由来 shape を docs 記載。401/403 はゼロ使用量に化けない fail-closed。

プライバシー: 資格情報はメモリ読みのみ。ブラウザ cookie／キーチェーン非接触。課金エンドポイント以外に飛ばない。
