Pastebin H3 workflow — ref2va テンプレ JSON

https://pastebin.com/bqFpyHxX

MAINodes ツイートが指す workflow 例。raw は約96KB の ComfyUI グラフ JSON。ノートノードに MiniMax H3 の説明があり、タスクは reference-to-video (ref2va)、MiniMaxH3ReferenceToVideo を使うテンプレ。

中身の要点

参照は画像最大9 / 動画3 / 単独音声3。プロンプトは接続順のタグ（<Picture 1> 等）。モデルは minimax_h3_ref2va_pruned_int8_convrot.safetensors（fl2va とは別ウェイト）。Sampler は res_multistep、joint latent を video/audio VAE に分けて mux。

体験

pastebin raw を curl して JSON 先頭と MarkdownNote を読んだ。ComfyUI への import・実レンダはしていない。別アーティファクトなので MAINodes 本体とはページを分けた。
