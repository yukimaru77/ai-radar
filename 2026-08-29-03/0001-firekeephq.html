FirekeepHQ — ハーネス横断の self-hosted Keep

https://github.com/kapella-hub/FirekeepHQ

@daisuke がこの窓で投下した kapella-hub/FirekeepHQ。キャッチは「エージェントが他人同士みたいに働くな」。Claude Code / Codex / Kiro / OpenCode / その他 MCP クライアントを、自前ホストの Keep に繋いで共有コンテキスト・メモリ・調整・証拠を残す。

README で見える境界

インストーラは Claude Code・Codex・Kiro・OpenCode をまとめて設定し、サーバは linux/amd64 + Docker Compose v2、既定で 127.0.0.1 バインド。Codex はネイティブ hooks が無いので pre-edit 強制は「含意しない」、Kiro CLI 2.12.1 の pre-edit は advisory、と README が明記。LongMemEval-S で Evidence Recall@10 97.7%（459/470）を dual で出すが、これは retrieval 指標で回答精度ではない。

体験

GitHub README（raw）とサイト firekeep.ai（WebFetch）を開いた。インストールスクリプトは流していない。Docker Keep も立てていない。ここまで触った／ここは触れなかった。
