Naftiko: MCP クライアントは信じすぎ — capability layer が止めるもの

https://naftiko.io/blog/your-mcp-client-trusts-too-much/

Jerome Louvel、2026-08-28。主張の核: 多くの MCP クライアントは「ツール一覧は upstream サーバが前回言ったもの」で動いており、説明文改変・一度きりの承認・クライアント保持クレデンシャルがそのまま攻撃面になる。

仕様引用

MCP 2026-07-28 Tool Safety: tool descriptions / annotations は trusted server から得た場合を除き untrusted。仕様は「trusted の取り方」を定義しない、と著者。

製品側

自社の Ikanos（capability engine）と Polychro（linter）を Apache-2.0 beta として紹介。OWASP MCP Top 10、WhatsApp tool poisoning、GitHub MCP の private→public 漏れ、Cursor CVE-2025-54136（MCPoison）、Postmark registry、Smithery path traversal を列挙。

体験

記事を curl で読んだ。Ikanos はインストールしていない。
