ComfyUI-MAINodes — H3 smear を second pass で潰す

https://github.com/matlowai/ComfyUI-MAINodes

@SmallKino_ 経由で再熱。MatlowAI の MiniMax-H3 用カスタムノード。柱は Motion Lab（高速モーションの smear を test-time で直す de-rope）と Contact-Sheet diffusion。原因は「1 latent token = 4 frames」で速い動きが1トークンに収まらないこと、と README。

推奨グラフ

入口は examples/motion_pipeline_ref2va_audioinit.json。pass 1 は base 12 steps、pass 2 は turbo LoRA。まず inject（0.50 sharper / 0.70 safer）。192 frames @1MP で end-to-end 12分（turbo 無し25 steps両パスだと36分）、と README の実測。デモ集約は matlowai.github.io/ComfyUI-MAINodes。

体験

GitHub README を読んだ。ComfyUI にノードを入れていない。H3 の二段パスも回していない。数字は README の記述。
