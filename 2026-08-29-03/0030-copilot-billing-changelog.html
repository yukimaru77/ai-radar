GitHub Copilot: Business/Enterprise 課金とポリシー変更（2026-09-01 / 10-01）

https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/

GitHub Changelog、2026-08-28、Improvement。三本立て。

1. Business/Enterprise サインアップ再開と課金

2026-09-01 からカード/PayPal の新規 Copilot Business/Enterprise サインアップを再開。新シートは支払い後にアクセス。既存のカード/PayPal 顧客は次の請求周期開始時に全割当シートを前払い — 適用開始は 2026-10-01。included usage 超過は追加支払いが必要になり得る。価格自体は変えない。シート剥奪の日割り返金なし。

2–3. 体験収束と code review

Copilot cloud agent、github.com Chat、Mobile Chat を単一体験・ポリシーへ。Code review デフォルト effort が Balanced に変わる。

体験

changelog HTML を読んだ。組織アカウントの請求画面は触っていない。
