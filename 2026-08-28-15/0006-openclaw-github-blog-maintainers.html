GitHub Blog: OpenClaw メンテナーと「prompt requests」

https://github.blog/open-source/maintainers/openclaw-went-viral-meet-the-maintainers-building-and-securing-it/

GitHub Blog「OpenClaw went viral. Meet the maintainers building and securing it.」を開いた（2026-08-27 前後の公開、レーダーでは 08-27 に一度読んだ内容の再確認）。最速成長プロジェクト、という位置づけ。

数字（記事本文）

2025年11月起点から、2026-08-26 時点で約 388,000 stars / 81,000 forks / 80,000+ commits、と記事にある。Peter Steinberger ほかメンテナーのインタビュー形式。

教訓（抜粋）

見出しどおり Pull requests が prompt requests になった。差分だけでなく agent transcript・スクリーンショット・テスト・思考の説明が新しい信頼シグナル、とメンテナー側が語る。既存 PR の duplicate を reputation 攻撃に使う動きも観測。Safe-by-default は誰に聞くかで意味が変わる。GitHub Secure Open Source Fund session 4 との接続も本文にある。

体験

記事 HTML は開いた。OpenClaw 本体のビルドや PR レビューはしていない。
