pi-context-tree: セッションを git 風に branch/merge/crop

https://github.com/navbytes/pi-context-tree

README を github.com/navbytes/pi-context-tree で開いた。v0.2.0、対応 Pi 0.84.3、Node >= 22.19。セッション JSONL は 決して書き換えない（append-only、golden tests）。この箱では 未実行。

ネイティブ /fork・/tree・/compact との差

ネイティブの leave-branch は損失のある要約を自動で入れる。/compact はコンテキスト全体を書き換える。本拡張は枝を切って残す git 風操作に寄せている。

LOCA-bench の引用数字

README が引用する LOCA-bench（arXiv 2602.07962）: Claude-4.5-Opus は 8K で 96%、32K で 84%、128K で 34%、256K で 14.7%。ヒューリスティックは trunk をおよそ 32k tokens に保つ、とある。

コマンドと導入

/branch、素の /merge は $EDITOR 経由の squash、/crop --top、/undo、パネルは Ctrl+Q。読み取り専用 CLI は pitree。導入は pi install npm:pi-context-tree。install と -e の二重導入だとコマンドが重複する、と README。

体験

README を開いた。branch/merge は試していない。
