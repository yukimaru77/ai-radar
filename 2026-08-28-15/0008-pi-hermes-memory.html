pi-hermes-memory: 永続メモリ + FTS5（Hermes移植）

https://github.com/chandra447/pi-hermes-memory

README を github.com/chandra447/pi-hermes-memory で開いた。Pi 向けの永続メモリ + セッション検索 + 秘密情報スキャン。Nous Hermes agent からの移植。この箱では 未インストール・未実行（README / ページを開いただけ）。

インストールとデータ場所

導入は pi install npm:pi-hermes-memory、または git:github.com/chandra447/pi-hermes-memory。コマンド例 /memory-index-sessions。データはグローバル ~/.pi/agent/pi-hermes-memory/ とプロジェクト別 ~/.pi/agent/projects-memory/<project>/。セッション検索は SQLite FTS5。

メモリ方針とピン

MEMORY.md / USER.md は 5000 文字。skill_manage は SKILL.md へ。scanContent が API キー / トークン / SSH をブロックする。既定の memoryMode は policy-only（全文 MEMORY.md ではなく <memory-policy> を注入）。/memory-pin は STANDING.md、最大 20 エントリ / 2000 文字で、エージェント側からは書けない。

移行・注意点

v0.7.10 は ~/.pi/agent/memory と flat skills を自動移行。Homebrew Pi では better-sqlite3 の ABI 警告あり。CJK の trigram は 3 文字以上が必要。区切りは §。レビューは 10 ターンごと、または 15 tool callごと。llmModelOverride の例に openrouter/deepseek/deepseek-v4-flash が出るが、こちらでは設定していない。
