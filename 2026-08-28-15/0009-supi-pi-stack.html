SuPi: Pi に LSP+AST を載せる拡張スタック

https://github.com/mrclrchtr/supi

README を github.com/mrclrchtr/supi で開いた。SuPi（Super Pi） は earendil-works の Pi 向け TypeScript 拡張スタック。Pre-release。この箱では 未インストール、install.sh も実行していない。

核となる拡張

肝はモデルが呼べるツールとしての LSP + Tree-sitter（supi-code-intelligence）。ほかに supi-web、Context7、supi-ask-user、supi-context / cache / debug、supi-skills（$ で開始。状態は enabled / model-invocation-disabled / disabled）。Beta: supi-review、supi-agent、supi-insights、supi-claude-md。

インストール（README の注意）

curl scripts/install.sh | bash（README は 先にスクリプトを読めと明記）か、pi install npm:@mrclrchtr/supi-code-intelligence。Tree-sitter は同梱。フル LSP には言語サーバーが PATH 上にある必要がある。導入後は /reload。
