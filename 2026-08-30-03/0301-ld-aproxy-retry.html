linux.do/2830301: 上流不安定で夜の仕事が死ぬのでローカル無限リトライ

https://linux.do/t/topic/2830301

@MoYeRanQianZhi。Claude Code / Codex が上流の揺れで夜の /goal を落とす。CC と Codex にもリトライはあるが、種類によっては飛ばし、回数上限があり、間隔を自分で決められない。CC Switch の上限は 10。New API は重いので、ローカルの無限リトライ中継 aProxy を Rust 2024 で急いで原型化する、という貼り付け。

設計メモ（貼られた /goal）

設定は ~/.aproxy/。ローカル専用のデーモン。既に動いていたら二重起動しない。エラーなら無限に続ける。ネットワークだけでなく、認証エラーや BAN も対象にしている。遅延は最初3回が 0 秒、そのあと 5 秒から倍々で 320 秒、以降は 5 分。初版は URL 1本の透過。API Key はヘッダの追加/上書き。プロキシ設定必須。

PS: モデルが無くて散らかっているので当面は非公開。コードブロックはスレに貼ってあるだけ。

体験

スレ JSON の本文を読んだ。公開リポジトリは無く clone できない。貼られた仕様は読んだが、デーモンは動かしていない。認証や BAN まで無限リトライするのは危険側。ここまで触った／ここは触れなかった。
