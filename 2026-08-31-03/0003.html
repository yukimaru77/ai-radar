公式の意味: disable-model-invocation: true はモデル駆動パスを全部閉じ、人間が /name したときだけ走る。docs の例は commit / deploy / send-slack-message。「コードが ready に見えるから Claude がデプロイする」を止めたい人向け、と docs 自身が書く。v2.1.196 以降は scheduled task の prompt としても走らせない。サブエージェントへの preload も止める。

鏡のフィールド user-invocable: false は UI から消えて Claude はまだ読める。2026-01 の docs issue がこれを shadow tool と呼んだ。両方 true/false を組み合わせると VS Code docs は disabled skill と呼ぶ。ディスク上の1本は user_invocable: true（underscore）で、docs の hyphen と食い違う。true がデフォルトなので今回は無害。false だったら「隠したつもりで / に残る」。
