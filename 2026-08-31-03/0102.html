doofzoff/SIMURG — 197,632 chars/sec で崩壊を ~590 字で切る

https://github.com/doofzoff/SIMURG

Apache-2.0、Python、gh api 時点で 38★ / 15 forks、2026-07-20 作成、最終 push 2026-08-29 18:47 UTC。説明文は「Zero-leak online detection of LLM decoding corruption」と Free Web Search。トピックに hallucination-detection / vllm / streaming。

README の表をそのまま写す。throughput 197,632 chars/sec（laptop CPU）、detection latency ~590 chars past corruption onset、依存は numpy only、GPU なし、setup 3 lines。50 tok/s のストリームは ~250 chars/sec、SIMURG は 197,000 を読むのでボトルネックにならない、と書く。失敗モードは repetition collapse / cross-lingual drift / regurgitation / structural breakdown（#REF! -0.00）/ template leakage。

ゼロリークの主張：hold window 内の onset なら悪いトークンはユーザーに届かない。過ぎた場合はクリーンな接頭辞 + 最大 ~900 chars の悪い尾をリトライで置換。論文は HAL-X AI 2026、13 pages、repo 内 paper/simurg_paper.pdf。Monolith（1.0.2）と TinyFish の無料 web search 節もあるが、計測の核はガード。「これは事実幻覚ではない。流暢だが間違った文には統計的傷跡がない」。
