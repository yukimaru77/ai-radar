HermesがHy4 mixed quantのツイート+HFからQwen 3.6用レシピを自作。Mac版も聞く

https://x.com/hermitdave/status/2094120791205949941

@hermitdave。Hy4 mixed quant のツイートと HF を Hermes に渡し、Qwen 3.6 向けプランを生成させた。Mac compatible variant が欲しいかまで聞いてきた。

「it even asked if I wanted mac compatible variant」

quant レシピを人間が読む代わりに、剤に「この tweet + この repo から自分のモデル用に書け」と渡している。出力の正否・どの Hy4 カードかは、この投稿では未検証。スキャンも HF URL を置いていないので発明しない。

同じ窓の mixed quant 実体は GLM-5.3 側: light_foundry が 8× Spark で Int4-Int8Mix 377GB + DFlash2 k=7。公開カードは QuantTrio 5.3 URL が 401/404 で、Tech2wild が 282 shard ~378GB、「QuantTrio-style recipe」と自分で書く。Hermes がやっているのはその類の移植下書きを、Qwen 3.6 向けにエージェントへ外注する作業。

所感

現場のグレー: 他人の mixed quant 手順を別モデルへ移植する下書きを剤にやらせる。Mac 分岐を聞いてくるのが Hermes らしい。正否は人間が header / layer map を照合するまで分からない。

体験

X 本文はスキャン原文。Hy4 の HF カードも Qwen 3.6 レシピも開いていない。Hermes に同じ作業は投げていない。GLM mix の方は Tech2wild / DFlash2 カードを WebFetch 済み（別ページ）。
