Herdrの1ペインで5h+週次を%表示。Claude/Codex/Grok/Agy/OpenCode/Pi

https://x.com/guannanjiayou/status/2094124468654551304

Herdr に全部載せている理由は「一つのペインで全部見る」だと @guannanjiayou。そこに 5h と週次の残り%をライブで出す小さなプラグインをボルトオンした、という一人称。対象は Claude / Codex / Grok / Agy / OpenCode / Pi。llmquota や statusline 燃料計の次の OSS として、メーターとセッション観測が同じ面に乗った。

「Same reason I keep everything in Herdr — one pane to watch them all. I bolted on a small plugin that also shows live % quota left per session (5h + weekly, Claude/Codex/Grok/Agy/OpenCode/Pi)」

親スレで @theaaron が Grok Bot を Herdr に載せたい理由は terminal sessions を見たい、だった（https://x.com/theaaron/status/2094107274394677754）。この投稿はその面にクォータ%を足した実装報告。

GitHub は https://github.com/levi-qiao/herdr-agent-quota。この窓の SKIP に既出なので別ページは切らない。README を gh api で読んだ実体: サイドバー例は 5h 100% 3h07m · 7d 31% 2d3h、cache 99.6%、context 23%。Herdr 0.8.0+ / Rust 1.95+ / macOS or Linux。./install.sh。

Coverage 表（README 原文）: Claude Code は 5h+7d と statusLine の prompt_cache expiry。Codex は Canonical ChatGPT login（API key は subscription quota ではない）。Grok は 7d。Agy は 5h+7d。OpenCode は Go の 5h+7d（30d は dashboard）。Pi は openai-codex OAuth が同じ Codex account id のときだけ既存 Codex quota を安全にマッチ。色は残り%と残り時間のペース比較（緑=on pace、琥珀=ahead、赤=ahead かつ 20% 未満）。

OpenCode Go はメンテナー自身がサブスクを持っていない。ローカル session / credential / fail-closed は OpenCode 1.18.20 でテスト。成功時の usage 形は CodexBar 由来で、このリポが観測した応答ではない、と README が先に書いてある。401/403 を 0% にしない。

所感

ハーネス横断の燃料計は「見えた数字を信じる」より attribution 規則の方が本体。Pi が Codex 枠を借りる条件、OpenCode Go が未実測、という fail-closed の書き方が現場向け。
