DESIGN.mdを1枚置く。Linear/Notion等2,000件のデザイン言語をトークン化する

https://x.com/codex_lab_/status/2094091484320657619

@codex_lab_。Linear / Notion / ElevenLabs など 2,000 件のデザイン言語を DESIGN.md にトークン化してエージェントに渡す。対象ハーネスは Claude Code / Codex / Cursor / v0。実装は Tailwind v4 と CSS 変数。ライブラリ本体は https://styles.refero.design/（別ページ）。

同窓の @rpa_dake: 「“AIのダサいUI”って結局デザイン言語を渡せてないだけ」（https://x.com/rpa_dake/status/2094123432170688796）。導入物は同じサイトなので、このツイートはライブラリ告知、rpa_dake は JP の一言として別ページ。

所感

プロンプトで「いい感じに」と言う代わりに、実在プロダクトのトークンを1枚渡す。v0 まで列挙しているのが、コーディング剤だけでなく生成 UI 側にも効かせたい意図。

体験

X 本文はスキャン原文。サイトは WebFetch で開いた（別ページ）。DESIGN.md を Claude Code / Codex に渡して画面を生成する実験はしていない。
