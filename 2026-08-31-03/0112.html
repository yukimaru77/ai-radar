gryph.sh — 剤の read/write/exec をローカル SQLite に残す

https://gryph.sh/

ランディング見出し「Your agents. your controls.」。Gryphdocs ★1.2k と表示。主張：コーディング剤は記録も上限もなく read/write/command する。Gryph は各アクションを記録し、実行前にポリシーを掛ける。デモは write を ALLOW、破壊的なコマンドを BLOCK、policy: no-destructive · claude-code。

対応として名指し：Claude Code、Cursor、Gemini CLI、OpenCode、Windsurf、Codex、Pi Agent。Observe / Control / Verify / Integrate / Author。YAML + CEL。セッションに署名付きレシート。JSON Lines export。データはローカル、No cloud / No telemetry、SQLite。Apache 2.0。「9 tracks · self-paced · runs on your machine」。

クエリ例：gryph query --action file_write --count → 14。gryph sessions に claude-code 22 events / cursor 9 events。ランディングの数字はデモ。実測のブロック率は書いていない。

体験

WebFetch のみ。CLI を入れて Claude Code にフックしていない。ブロック実験はしていない。★1.2k はランディング表記で、GitHub API は叩いていない（リポジトリパスがページ本文にフルで出ていない）。
