arXiv 2608.20614 — Skill Lift 平均 0.2134、スキャン同士は ρ=0.14

https://arxiv.org/abs/2608.20614

ACES（Agentic Continuous Evaluation of Skills）。著者は NVIDIA の Christopher Kevin ほか。スキルを実行可能な剤アーティファクトとして評価する。paired live trials（スキルあり/なし）、軌跡を ATIF に正規化、既定 6 メトリクス、報告量は Skill Lift。

数字を abstract / §6 から写す。文書スキャン：内部+公開カタログの 145 スキル。structural と LLM-judge の Spearman ρ=0.14（Pearson r=0.08）。structural の default C-grade（70点）は 94.5% が通るが、80点は 48.9%。平均 structural 79.2（median 79.8、σ=4.9）。フロントマター tools 未宣言 99.3%、Limitations 欠 97.9%。

ライブ：本番 64 スキル中 58、4 ハーネス、947 scored paired cases。mean composite Skill Lift 0.2134（95% CI [0.1967, 0.2301]）。outcome-only（accuracy と goal accuracy の平均）0.1799。composite が正は 72.8%（689 / 171 zero / 87 negative）。絶対値は with-skill 0.7460 vs baseline 0.5326。ハーネス診断：OpenCode 0.3611、Claude Code 0.2904、Codex 0.1264、Terminus-2 0.0896。同一 Codex ハーネスでモデルを強くすると baseline が上がり Lift が縮む、と §6.5。

公開実装は NVIDIA SkillEvaluator。スキャンとライブの相関はほぼゼロ（Tier1 ρ=-0.0181、Tier2 ρ=-0.0266）。「文書が綺麗」は実行の代理指標にならない、が論文の喧嘩の中心。
