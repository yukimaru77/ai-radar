DFlash 2: Keep Drafting Parallel。selector+convでverifyあたり+16–25%

https://inco.ai/blog/dflash2/

Inco AI ブログ（WebFetch）。DFlash は 2026-01 リリース、いま SGLang / vLLM / TensorRT-LLM / llama.cpp。NVIDIA は Blackwell で最大 15× throughput、Google は TPU で 3× tok/s、CoreWeave の Kimi K2.7 Code 本番（Artificial Analysis でそのモデル最速）は DFlash がデフォルト。HF の DFlash 系ダウンロードは 2026-08 時点で 350 万超。

DFlash 2 は parallel drafting を一段: 検証1回あたり出力 +20% 超、cycle latency は約 +1%、出力は証明可能に不変。ベンチで 16–25%。Qwen3.8-27B ドラフタで SGLang batch 1 が AR の 2.7–3.4×。

selector: 各位置 top 16、隣接点の pairwise score。Qwen3-4B GSM8K で Recall@1 は pos0 85.4% → pos6 72.9%、Recall@16 は 99.5% → 87.8%。oracle なら acceptance 4.27 → 6.79。実セレクタは +2.0M params、latency +0.6%、T=0 で 4.61（DFlash 4.27、DSpark +77.8M は 4.49）。convolution は two-tap dynamic depthwise、+3% params / +0.7% latency で 15-layer に近づく。合わせると Qwen3.5-4B mean acceptance MTP 4.54 / DFlash 4.92 / DSpark 5.49 / DFlash2 5.97。

今日出すドラフタは Qwen3.8-27B と Meta Muse Glimmer。Qwen3.8-27B mean: MTP 4.28 / DSpark 3.62 / DFlash2 4.80。Glimmer: DFlash 4.44 / DSpark 4.48 / DFlash2 5.70。GLM-5.3 用はこの記事の「今日出す2本」には入っていない。GLM 用カードは別ページ https://huggingface.co/incoai/GLM-5.3-DFlash2。

エンジン例（記事）: SGLang は git HEAD の sglang[all]。vLLM は PR 52816。llama.cpp は PR 27342、--spec-type draft-dflash。Ollama は PR 17865。oMLX は prebuilt。Run it now のモデルパスは Qwen3.8-27B 向け。

所感

ブログは Qwen/Glimmer の話が主で、GLM-5.3-DFlash2 の Spark 数字は light_foundry 側。selector が DSpark より 40× 小さく 16× 低遅延、が技術的な核。
