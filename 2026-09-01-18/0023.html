Flash-Next VRAMベンチがprivate→public。8GBで36 tok/s、GPUなし8.5、96GBで109

https://github.com/lukaLLM/Qwen3.8-Flash-Next-VRAM-Benchmark

Reddit p74pjwa: 誤って private にしたリポを public に戻した。親スレは 1w3pl64。

master README: Qwen3.8-Flash-Next（125B MoE、6B active）を RTX PRO 6000 1枚 + 96GB RAM、llama.cpp。176.94B のうち 51.2B は lookup table で matmul ではない。table をシステム RAM に置けば 8GB カードでも、GPU なしでも動く。

lookup を GPU に置くと decode が 55.6× 遅い。最大の無料レバーは --load-mode none で同一配置でも prefill 1.87×。

decode 梯子: no GPU 8.3、8 GiB 35.7、16 GiB 37.9、24 39.0、32 42.2、48 51.7、96 GiB 109.1 tok/s。ベースライン 109 decode / 1,955 prefill @2048。

スコアはファイルから再計算。初期3本は 158/98/105 tok/s に見えたが、モデルが tool-call 構文だけ吐いてコードを書いていなかった。

「96GB で何 tok/s」より「table を RAM に逃がす」が本丸。Atom しない。
