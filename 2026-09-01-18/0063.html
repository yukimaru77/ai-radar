Claude Code を五層に割る。主循環はツールを実行しない

https://juejin.cn/post/7680119725196820480

掘金。百工蜂Agent「Claude Code 整体架构与设计」。2026-09-01 12:43 JST。

「Claude Code 是一个基于大模型的编程 Agent：模型负责决策，它自己这几十万行 TypeScript 负责把决策变成动作——执行工具、管理上下文、守住权限。它有三种交付形态：命令行工具（CLI）、可嵌入的 SDK、MCP 服务。三种形态不是三份代码，来自同一条代码库。」

「这条代码库整体上分五层：入口 src/entrypoints/；装配 src/main.tsx；引擎 src/query.ts；能力 src/tools/、src/commands/、src/services/；支撑 src/utils/permissions/ 等。」

「消息进入引擎层 query.ts 主循环；主循环把消息连同工具清单发给模型；模型要求调用工具时，执行交给能力层——先过校验、权限、Hook，再真正执行。」

「注意：主循环自己不执行任何工具，整个流程里也不存在一个统一调度的总管——每一步只和相邻层的接口打交道。」入口は cli.tsx / mcp.ts / sdk/。macOS 起動で钥匙串を順に読むと約 65ms 余計、とソースコメント由来の数字を本文が引く。

所感

ハーネス解剖の本命。主循環がツールを持たない、が設計の芯。CLI/SDK/MCP は入口ファイルだけ増やす。
