firefly: R3F の 3D 数字人。同源 /api/chat と Serverless 10秒の意図プリフェッチ

https://juejin.cn/post/7680216488122138634

掘金。Erishen。本番は firefly.erishen.cn。GitHub erishen/firefly。

「把一个 LLM 接进 3D 场景，让一个 VRM 虚拟角色能听懂你说话、开口回应、眼神还跟着你转」だが、ぶつかったのは「Key 不能进前端、Serverless 函数有 10 秒硬上限、R3F 的 Canvas 不穿透 React Context、语音识别在国内还不稳定」。

「firefly 的做法是浏览器永远只和同源的 /api/chat 通信，真正的 Key 只在服务端 .env（本地）或平台环境变量（线上）。」

「线上最初反复报 504 / 没返回 的根因」は 10秒上限。解法は「服务端意图预取：请求进来先用正则判断用户是不是在问天气/商品，若是就在服务端提前把数据拉好、作为系统上下文注入。」

「R3F 的 Canvas 读不到外部 Provider 提供的值。」i18n は Context を捨てて module store + useSyncExternalStore。VRM は 14.5MB、Cache API で秒開。redistribution=disallow のためモデルはリポに入れない。

所感

3D に見えるが中身は Serverless 10秒と Canvas が Context を貫かない問題。
