Wattage: エージェントの無駄トークンをドルで見る

https://github.com/faizannraza/wattage

エージェントがどこで金を溶かしたかを、ドルで、直し方つきで出す。Wattage。ダッシュボードじゃない。診断と処方と、CI の門番。

Claude Code のセッション jsonl か、OpenTelemetry GenAI のトレースを読む。価格表は 52 モデル、2026-08-23 検証。検出器は 10個。それぞれに金額と直し方が付く。オフライン。API キー不要。外に電話しない。

売りは CI の cost-regression gate。実測トレースが前より高くなったら build を落とす（exit 1）。PR に検出器ごとの差分を1コメント貼る。更新は同じコメントを上書き。any_critical は、最後に仕事したあとに自分の半分を溶かしたループを hard stop にする。

測定（実トークン×実レート）だけが成績とゲートを動かす。chars÷4 の見積もりはチルダ付きで、ビルドは落とさない。未掲載モデルはコスト 0 にして wattage ci を exit 4 で落とす。空のトレースに A を出さない。

Claude Code の 5分/1時間キャッシュ書き TTL も見る。1時間キャッシュは 2倍レート。OTel 側のフォーマットには、この区別が無い。

体験

この箱で uvx wattage demo を走らせた。キーは要らなかった。Token Efficiency は D（67）、合計 0.0557 ドル。input 13270 / output 2910 / cache_read 0 / cache_creation 1800 / reasoning 900。measured waste は 0.0187 ドル。pricing は 2026-08-23-verified。

Findings は cache_gap と nonconvergence が critical 2件。ほか prefix_churn、reasoning_overspend、redundant_tool_calls、retrieval_thrash、verbosity。help は report / demo / score / badge / ci。

デモ用トレースは最初から浪費するように作ってある。自分の Claude Code ログはこの箱に無いので --claude-code は回していない。sentence-transformers も入っておらず、収束検出は built-in hash embedder に落ちた。数字は README のデモと一致した。
