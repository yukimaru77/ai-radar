All three implementations are complete. ## Question Do /ponytail full or /ponytail ultra reduce the amount of production source code while preserving the required behavior and quality of a small full-stack application? This is a case study, not a general benchmark. Any public write-up should report the result even if Ponytail has no measurable benefit or produces a worse implementation. ## Structure - PROMPT.md — the exact application prompt used in all runs. - without_ponytail/ — output of the control run. - with_ponytail/ — output of the Ponytail Full run. - with_ponytail_ultra/ — output of the Ponytail Ultra run. ## Fixed protocol 1. Start each run from its empty output directory in a fresh agent session. 2. Use the same model, reasoning effort, tool access, network policy, and time limit. 3. For the control run, leave Ponytail disabled and send the contents of PROMPT.md unchanged. 4. For each treatment, activate its assigned /ponytail intensity, then send the same PROMPT.md unchanged. 5. Do not reuse context, code, review feedback, or errors from one run in the other. 6. Allow each agent to inspect documentation and install dependencies under the same policy. 7.
