V2EX: Runner — Claude CodeとCodexをNDJSONで結対

https://www.v2ex.com/t/1238185

yicheng47（18:38 JST、replies 0）。Claude Code と Codex を同時に開き、コピペで繋いでいた現場から Runner を作った一人称。

「四月份开始，我日常写代码基本是几个 agent CLI 同时开着：Claude Code 写，Codex review ，偶尔再开一个查资料。…于是我做了 Runner」

通信はローカル NDJSON バス。「之前试过让它们用 Markdown 文件互相留言， 几轮之后 markdown 消耗的 token 比较高…换成 NDJSON 之后，配一个小 CLI（runner msg / runner signal）」

「coder 用 Claude Code ，reviewer 用 Codex （或者反过来）。两个模型的盲点不一样…这个循环有时候能自己跑几个小时不用我插手」

「runtime 支持 Claude Code 、Codex 、TRAE CLI ；本地直接调你装好的 CLI…没有任何托管层」。macOS Apple Silicon only。フロントは Tauri から GPUI へ書き換え、と本文。

GitHub は別頁（0305）。fetch 実測は 75★ / GPL-3.0 / v0.6.7。
