Vladislav-Kalinkin/ullis — RWKV-8 Heron + 1-bit ROSA ローカル訓練

https://github.com/Vladislav-Kalinkin/ullis

Vladislav-Kalinkin/ullis。gh api 時点で 1★、MIT、Rust。RWKV-8 Heron / ROSA を Apple Silicon で回すローカル訓練器。

README: 「Ullis trains RWKV-8 Heron / ROSA language models on Apple Silicon. The default stack is LayerNorm → ROSA-QKV-1bit → CMix x070」。

「This is not a claim of production chat quality. Ullis is a local trainer/infer that fits an M1 8 GiB Mac with a 4 GiB process budget」。

1-bit ROSA は activation alphabet であり weight quantization ではない。QKV bits は {0,1} from x > 0。admission budget は 4 GiB。8 GiB Mac で --memory-budget-mib 8192 を渡すな、と明記。

README に出ていたコマンド（未実行）: cargo test / cargo run -- --smoke / train 系。dataset contract で assistant.thinking 必須。
