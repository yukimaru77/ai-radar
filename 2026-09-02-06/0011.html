@YuriKushch（20:52 UTC、12連）。「Same Claude Code session. Same /compact. 500K tokens. warm: ~$0.70 / cold: ~$5.20 / The difference isn't how often you compact. It's whether the prompt cache was still alive. Which makes "stop compacting manually" exactly the wrong fix.」

要点: compactは会話末尾に要約指示を足すだけ → prefixはcacheヒット。Warmは入力の~10%、ColdはTTL切れのフル再読。「午後に5回compactする方が、昼休み後に1回するより安い」。出るときにcompact、戻ってからではない。auto-compactは窓が満杯＝最悪のタイミングで必ず撃つ。

/clearはタダ（/resumeで戻せる）。経路放棄は/rewind（cached prefixまで切る）。位置だけなら/recap（appendなのでprefix生存）。本物の連続は/compact。冗長出力はsubagent。ハンドオフはagentにファイルを書かせて/clear。# Compact instructionsをCLAUDE.mdに。

モデル切替・effort切替はcacheキーが別 → 会話全体をフル再読（compactより大きいリーク）。サブスクcache TTLは1h。API / Bedrock / usage creditsは5分。Fix: CLAUDE_CODE_PROMPT_CACHE_TTL=1h。/usageにwarm (1h TTL, last activity 40s ago)とexpected rebuild (compaction)が出る。
