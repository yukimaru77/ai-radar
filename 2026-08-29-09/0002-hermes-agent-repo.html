内蔵ラーニングループ：経験からスキルを作り、使用中に改善し、知識を残せと自分を nudges し、過去会話を検索し、セッション横断でユーザーモデルを深める。モデルは Nous Portal / OpenRouter / OpenAI / 自前。切替は hermes model。ターミナルバックエンドは local / Docker / SSH / Singularity / Modal / Daytona / Vercel Sandbox の7つ。メッセは Telegram / Discord / Slack / WhatsApp / Signal / CLI。cron は自然言語。サブエージェントと RPC でパイプラインをゼロコンテキストコストに落とす、と書いてある。
