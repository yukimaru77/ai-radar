README

Python のみ。ffmpeg 実行ファイル不要。入口は extract_sharpest_frame.py（CLI）と extract_sharpest_frame_gui.py（日英切替 GUI）。OpenCV で読み、Laplacian 分散でシャープネス、チャンクごとに最良を JPEG/PNG。依存は opencv-python と tqdm。GUI は Tkinter。

python extract_sharpest_frame.py --video /path/to/video.mp4 --chunk-size 30 で 30fps なら1秒間隔。ワーカー数指定、_sharpness_metadata.csv 再利用、--analysis-only。GUI に stop と既存 metadata の確認。

Windows バイナリ＋GUI は BOOTH 有料。無料 Python に無いもの：YOLO 自動マスク（人・車）、マルチプロセス高速化、類似フレーム除外、カスタムマスク、動画レンジ、SAM3 テキストプロンプト、バッチ複数動画、OSMO360/AVATA360 の preset seam mask（V1.0.0, 2026-08-01）。ガイド本文の SAM3 Dual Mask はこちらの有料側。
