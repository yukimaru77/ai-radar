2DGS Slang playground（WebGPU / 微分可能）

https://shader-slang.org/slang-playground/?demo=gsplat2d-diff

窓内の 3DGS は薄い。これはブラウザで回る 2D Gaussian Splatting の微分デモ。ツイート @cudaeducation は別名 URL try.shader-slang.org/?demo=gsplat2d-diff を貼っていた。こちらは指定の shader-slang.org を開いた。

ページが実際に返したもの

HTML は SPA。タイトル Slang Playground。#loading-screen に「Loading Playground...」。コンパイラはブラウザ内、サーバにコードを送らない、とヘルプ。Compile 先は SPIR-V / HLSL / GLSL / METAL / WGSL / CUDA。Run は WebGPU の compute shader（[shader("compute")]）。DXIL はブラウザ不可。

デモメニューに 2D Splatter と Differentiable 2D Splatter が並ぶ。WebFetch のレンダリング結果は「Browser does not support WebGPU, Run shader feature is disabled。」画像は出ていない。

デモソース（別途取得）

https://shader-slang.org/slang-playground/demos/gsplat2d-diff.slang が 200 で 960 行。先頭コメント：3DGS 論文（Kerbl et al.）の簡略 2D 版。3D→2D 投影は無く、blob は depth 順（index 大＝遠い）と仮定。adaptive density control はしない。核は computeDerivativesMain() と splatBlobs()。Slang の bwd_diff(fn)、[Differentiable]、[BackwardDerivative(fn)]。フル 3D 実装は github.com/google/slang-gaussian-rasterization を参照、と書いてある。

定数：BLOB_BUFFER_SIZE 184320、NUM_FIELDS 9、GAUSSIANS_PER_BLOCK 256、WG 16×16。Adam η=0.002, β1=0.9, β2=0.999。ターゲット画像は static/jeep.jpg。バッファは playground 属性で RAND / ZEROS 初期化。

体験

playground HTML と .slang ソースを取った。WebGPU はこちらの fetch 経路では無効で、jeep へのフィット画像は見ていない。Run ボタンは押していない。レンダを捏造しない。
