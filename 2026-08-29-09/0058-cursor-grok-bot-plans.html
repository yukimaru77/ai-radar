リンクは usage grant であり Cursor プランではない。既存 Pro/Ultra/Teams は残る。リンクは永続で unlink / 付け替え不可。

Grok Bot usage is metered on your Cursor account, not on Grok. A SuperGrok link grants Grok Bot usage on that same Cursor account while SuperGrok stays active. It does not create a second meter on Grok, and it does not change your Cursor plan.

週次 included が尽きたら、on-demand が有効ならアカウントの共有 on-demand spend。macOS と iOS は同一バケット。trial は日数ではなく usage credit（7日窓もあり）。消費は agent steps と tokens であり、メッセージ数ではない。大きいジョブで trial が一度に尽きうる。返さない。
