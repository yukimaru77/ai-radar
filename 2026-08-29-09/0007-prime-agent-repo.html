README の二本柱

Recursive Language Model (RLM)：コンテキストを変数（prompt-as-a-variable）、再帰サブエージェントを関数（programmatic tool / sub-agent calling）。永続 REPL の中。

Continual Harness：補足プロンプト、メモリ、スキル説明、再利用サブエージェント仕様を耐久状態として持ち、/refine で小さな証拠付き更新。ベースの immutable system prompt は書き換えない。スナップショットで rollback。

全部がプログラム：ファイル・シェル・ツール・サブエージェント・コンテキスト管理はコード経由。rlm(...) が子エージェント。スキルは import できる Python パッケージ。デーモンで端末を切っても動き、prime-agent attach で戻る。エージェント同士が直接メッセージ。

インストール：curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh。macOS/Linux。初回 /login。警告：モデル生成の Python とプロジェクトコマンドはユーザー権限。worker/kernel はライフサイクル隔離であり、セキュリティサンドボックスではない。

長時間向け：/goal、/heartbeat、prime-agent schedule、/autonomous（turn/token/time 予算と quality gate）。gate 通過は「その gate が検証したこと」だけで、上限到達は成功を意味しない。

models.json と今日のコミット

リポジトリ内に models.json は無い。ユーザー側は ~/.prime/agent/models.json（0006）。直近コミットは REPL フレーム修復、dispatcher envelope、bash output sentinel、connection models を read 時に導出、ライブ provider カタログからモデルカタログ再生成。ARC-AGI 95.5% を新機能として書いていない。既出荷の数字は別ページのまま。
