Lemmalog — Datalog engine for LLM agent memory

https://github.com/JordyZomer/lemmalog

0029 の Jordy Zomer ポストが紹介する別物——Lemmalog（https://github.com/JordyZomer/lemmalog）。「LLM エージェント記憶のための Datalog エンジン」。Rust クレート、MCP サーバ、REPL、agent skill、設計文書付き。

The thesis: an agent's memory should be a deductive database — the agent builds a verifiable model of what it knows and mechanically reasons over how that knowledge changes, rather than "remembering better" than a vector store.

README が実装済みと言うもの

層化 Datalog インタプリタ、否定、seminaive 固定点、bi-temporal 事実、why() 証明木、スコープ付きリトラクション、ask/ask_deep、BM25+エンティティ強化のハイブリッド retrieval、MCP サーバ（Claude Code / Kimi CLI 向け）、REPL（cargo run --bin lemmalog）など。Leapfrog triejoin / DBSP は future。

エンティティ解決は LLM が提案する alias(Local, Canonical) を Datalog 閉包にし、衝突は merge せず alias_conflict にする、と安全性をテスト付きで書いてある。
