TB-fn: 開源はSol maxから最大8.6pt落ち

https://fidian.ai/blog/tb-fn-benchmark-results/

Fidian（Hubert Chen、2026-08-26）。Artificial Analysis の Terminal-Bench 2.1 上位20モデルを、同じ89タスクから作った自前変種 TB-fn でも測り直す。「TB-2.1 で Sol 近辺に見える新規モデルは、本当に同等か？」への答え合わせ。

GLM-5.3 leads the open-weight families on both benchmarks, but its gap to Sol max grows from 1.0 point on TB-2.1 to 8.6 points on TB-fn.

Per-attempt cost increased by 41%.

数字と条件

・タスク数は TB-2.1 と同じ 89。ただし 88/89 プロンプトと全89 verifier を書き換え、アサーション平均 9.1→45.8。絶対スコアはラボ公表の TB-2.1 と直接比較不可、と caveats に明記。
・ハーネスは Terminus 2（harbor==0.20.0）＋ parse-failure circuit breaker / tmux wedge 回復 / 1800s timeout。
・pass@1 はタスク平均。上位は GPT-5.6 Sol (max) ~86%、Sol xhigh と Opus 5 各 effort ~82%。TB-fn のトップティアは OpenAI と Anthropic のみ。
・開源ファミリー（GLM/Qwen/Kimi/DeepSeek をグループ化。GLM-5.3 は家系として含めるが計測時点で自重み未公開と注記）では GLM-5.3 が首位だが、Sol max との差が TB-2.1 の 1.0pt → TB-fn の 8.6pt（77.6% vs 86.2%、7位、Tier 2a）。開源は TB-fn で Tier 1 に届かない。
・4σ超の落差6つ: Grok 4.5 ~−11、Kimi K3 ~−10、GLM-5.2 ~−9、Gemini 3.6 Flash ~−8、GLM-5.3 ~−7、DeepSeek V4 Pro ~−6。
・コスト: 全モデル全タスクで per-attempt 上昇。個別 約12–97%。中央値ターン 16→19、入力トークン平均 +45%、出力 +32%。リード文の「+41%」はこの全体像の要約。
・Opus 5 medium / xhigh / max はいずれも ~82% で、コストは約 $1.04 / $2.37 / $3.23（max は medium の約3倍で TB-fn ゲイン無し）。
・セキュリティ拒否は Fable 5 / Opus 5 / Gemini Flash 3.6–3.7 / Sol に確認。Fable を Opus 4.8 にフォールバック仮定すると TB-fn で約+10pt→~82% だが、Opus 5 も同時調整するとトップティア外に残る。

サービング経路は Anthropic/Google/OpenAI 直 API と OpenRouter（Grok/Kimi/DeepSeek/Qwen/Muse/GLM）。量子化やツール呼び出し整形の差は制御していない、と付録。TB-fn 本体は汚染防止で非公開のため第三者はタスク単位を再現できない。

体験

https://fidian.ai/blog/tb-fn-benchmark-results/ の取得 HTML を通読し、表の Sol max / GLM-5.3 / コスト列を照合した。こちらで Terminal-Bench や TB-fn を再計測してはいない。数字は記事の条件付き報告。
