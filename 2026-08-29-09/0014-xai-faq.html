xAI FAQ: Botメーターは別リセット

https://docs.x.ai/grok/faq

タイトルの期待と、今日開いたページの本文はズレる。ここは consumer Grok（grok.com / iOS / Android）の FAQ。Bot 専用 FAQ は docs.x.ai/grok-bot/faq。

共有週次プール（Chat / Imagine / Voice / Build / API）

「How do SuperGrok's weekly usage limits work?」：2026年6月ロールアウト。製品ごとの日次上限をやめ、1つの共有週次 usage pool を Chat / Imagine / Voice / Build に使える。好きな製品に全部使ってよい。リセットは Settings → Usage に表示されるスケジュール。

「How do I check my usage?」：Settings → Usage。

進捗バー、製品別内訳は API, Build, Chat, Imagine, Voice。週次リセット日時。Extra Usage Credits 残高。Bot という行はここに列挙されていない。

上限到達後は有料機能が一時停止。無料枠の Chat/Voice は別スケジュール。Extra Credits（web のみ、$5〜、1年失効、included より単価高）、プラン上げ、Auto Top Up。

Bot についてこの FAQ が実際に書くこと

What is Grok Bot? Grok Bot gives you durable AI teammates on a persistent cloud computer — messaging, approvals, connectors, and routines. It is not the same as Grok on grok.com or the Grok mobile apps. See Get started with Grok Bot.

それ以上のメーター説明は無い。共有プール reset が Bot を救う、とも、救わない、とも書いていない。別物だとだけ言う。

Bot 側の公式（今日あわせて開いた）：週次 included は Cursor アカウント上（cursor.com/help/grok-bot/plans）。grok-bot FAQ は週次 + on-demand、Cursor と SuperGrok 両方あるときは多い方。Settings and notifications の Usage & Billing は「weekly included usage and on-demand」で、Cursor アカウントページを見ろ、と書く。
