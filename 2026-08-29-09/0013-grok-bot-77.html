公式が実際に言うメーター境界

Cursor ヘルプ cursor.com/help/grok-bot/plans（今日開いた）：「Paid Grok Bot access includes usage that resets weekly. … Grok Bot usage is metered on your Cursor account, not on Grok. A SuperGrok link grants Grok Bot usage on that same Cursor account … It does not create a second meter on Grok。」週次 included が尽きたら、on-demand が有効なら共有 on-demand spend に落ちる。Heavy リンクは usage grant であり Cursor プランを増やさない。Ultra と Heavy を両方持っていても、Bot は Cursor アカウント上の週次バー。チャットの Heavy プールや Ultra の月次にオフロードする、というボタンはここに無い。

docs.x.ai/grok-bot/faq：「Grok Bot subscriptions include weekly usage; eligible accounts can add on-demand usage billed from model and token cost. If you have both a Cursor and a SuperGrok subscription, Grok Bot uses whichever has more usage。」サイズ（何トークンで何%）は非公開。

docs.x.ai/grok/faq の Settings → Usage は Chat / Imagine / Voice / Build / API の共有週次プール。リセット日時もそこ。Bot バーはこの画面の対象外（0014）。

体験

ツイート一次と、Cursor ヘルプ / grok-bot FAQ / grok FAQ を開いた。Grok Bot 0.30.0 の Usage 画面はこちらのアカウントでは見ていない。77% は本人の土曜朝の数字。公式は「サイズ」を出していない。
