H3がComfyUIのv.clone()回帰で半速〜4倍遅

https://www.reddit.com/r/comfyui/comments/1w13wfd/

r/comfyui の spacemidget75。PSA: 約3週間前から入ったバグで MiniMax H3 が半速〜確認によっては4倍遅くなる。直し方は一行削除だが、Comfy を更新すると戻る。

PSA: A bug crept in 3 weeks ago, that makes H3 run half as fast. Comfired twice now. Fixed below.

Remove v = v.clone(). If you update Comfy, the problem will return (which is how I know this is defintely a problem and how to fix it)

リンク先は Issue #15665（Comfy-Org/ComfyUI）と、原因になった PR #15486「Fix peak memory issue with H3. by comfyanonymous」。ピークメモリ対策で入った v = v.clone() が、フル解像度 H3 でメモリ帯域を殺して遅くする、という筋。詳細の数値・再現環境は Issue 側ページ（0035）へ。

ダンプ時点コメント0。声の価値は「アップデートで戻る」という運用上の罠を短く言い切っているところ。
