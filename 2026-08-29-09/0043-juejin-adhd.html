フックは Codex が 401 を調べるとき、認証フロー・ミドルウェア・Token・Cookie を先に書いて、実行コマンドは最後の 1 行、という現場。

用 Coding Agent 改代码，最磨耐心的情况之一，就是它明明答对了，答案却藏在一堆废话里。

你让 Codex 排查一个接口为什么返回 401，它可能先查认证流程，再分析中间件、Token 和 Cookie，顺手提醒你依赖版本也该升级了。全部看完之后，真正要执行的命令只有一条。

群で名前が面白くて開いた、が導入。プロジェクトは ayghri/i-have-adhd。診断でも治療でもなく、Agent の出力順だけ。

它给 Coding Agent 加了一套回答规则：第一行先放行动，多步骤任务编号，报错直接写位置和原因，每轮重新交代进度，结尾只留一个明确的下一步。

SKILL.md は 1 ファイル、10 条を 4 組

記事の要約。

  • 先行动：第一行先给答案或下一步；命令・パス・断片は説明の前。
  • 说进度：复杂任务拆成编号步骤，每轮说明已经完成什么。
  • 讲具体：时间用明确单位；报错写位置、原因、修复。
  • 删干扰：列表不超过 5 项；不写客套开场、重复总结、无关支线。

作者は The Adult ADHD Tool Kit を「松散参考」し、LLM が実行できる出力規則に落とした、と書く。ADHD の診断はしない。

它不会让 Agent 突然变聪明。它的目标是减少来回翻屏和追问“然后呢”的次数，让下一步行动更容易被看到。

入れただけじゃ開かない

記事のインストール節が一番実務。

Codex:

codex plugin marketplace add ayghri/i-have-adhd --ref main
codex plugin add i-have-adhd@i-have-adhd
codex plugin list

セッションで $i-have-adhd。記事の強調: 安装插件后不会自动开启。常駐するなら公式の出力規則を ~/.codex/AGENTS.md に足す。

Claude Code:

claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

呼びは /i-have-adhd。見えなければ /reload-plugins。常駐は touch ~/.claude/.i-have-adhd-always（SessionStart Hook）。切るのは stop adhd mode / normal mode、または flag 削除。

keyi先保留按需启用。排错、执行修改和推进长任务时打开；需要讨论方案、讲源码或审文章时，再决定要不要保留更完整的解释。
