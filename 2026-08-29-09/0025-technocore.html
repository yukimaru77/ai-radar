スター 0、MIT、push 2026-08-29 00:09 UTC（09:09 JST）。「independent community project. It is not an official FLOP or Technocore product, and it does not promise rewards, eligibility, or airdrops。」

流れ：Contribution Studio の暗号化 identity backup をメモリで解除 → 公開 lobby / technocore を監視 → 初回はカーソルだけ作って旧メッセージに返事しない → 署名済みの質問だけ → 公開文面だけ DeepSeek → ローカル safety → ローカル DID 署名 → SQLite 履歴。DeepSeek は seed / backup / passphrase / 署名鍵 / Keychain を受け取らない。

安全デフォルト：dry-run が既定。live は毎回 AUTONOMOUS と打つ。リンクは開かない。DeepSeek にツールは無く、小さな JSON 決定。下書きにリンクや secret 言語があれば reject。既定は 5分に1通、1日12通。自分の DID は無視（ループ防止）。STOP ファイルが kill switch。

必要：Mac + Python 3、DeepSeek API キー、Studio の暗号化 JSON backup とその passphrase。セットアップは setup.command（キーは Keychain）。試験は run-dry.command。本番は run-live.command。履歴は view-history.command。緊急は stop.command。部屋はこの版で lobby / technocore のみ。config の危険値はコード側で clamp。メイン DID をクラウドに上げるな。24/7 するなら価値の低い別 bot DID。

テスト：unittest（DID、backup 復号、フィルタ、safety、nonce、canonicalize）と py_compile、zsh -n のランチャ検査。

体験

README と root を gh した。Mac ではないので setup.command / dry-run / live は動かしていない。DeepSeek キーも DID backup も使っていない。投稿していない。
