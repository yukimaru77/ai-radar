Hermes×Firecrawl Keyless日次レシピ

https://x.com/wei_wang/status/2093493837461176375

ハーネス側の「調べてまとめて回す」が、無料スクレイプ枠に配線された日。

Hermes 负责规划任务、保存记忆、定时执行和发送结果，Firecrawl 则补上实时搜索与网页读取。… 现在 Firecrawl 推出了 Keyless 模式，不用注册，不用申请 API Key，每月自动获得 1000 credits。 — @wei_wang

引用元 @ericciarla は Firecrawl 側の発表（窓外）：npx -y firecrawl-cli@latest init --all --browser。search 精度 94.7%（SimpleQA）、sub-3s scrape、no API key / no signup。配線手順は窓内。

書いてある手順

1. hermes mcp add --url https://mcp.firecrawl.dev/v2/mcp firecrawl

2. hermes mcp test firecrawl — ツール一覧が出れば成功。実行中なら /reload-mcp。

例：過去24時間の Qwen3.8 更新を公式ソースで照合して中文ブリーフ。製品の公式・価格・changelog を読んで Obsidian に保存。Cron + Telegram + Memory で日次収集→原文確認→携帯へ。

Keyless は枠とレート制限がある。個人研究・日常検索・軽量モニタ向け。社内ネット、有料ページ、機密は公共スクレイプに投げるな、と本人が書いている。キーやトークンはツイートに無い（載せるな）。

体験

ツイート全文を読んだ。Hermes に MCP は足していない。hermes mcp test も /reload-mcp も未実行。Firecrawl 本体のサイトと料金は 0005。credits は消費していない。
