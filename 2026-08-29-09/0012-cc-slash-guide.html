Claude Code: /clear vs /compactが一番効く

https://www.aigeek.biz/2026/08/29/claude-code-slash-commands-guide/

@yokebeto が「毎日使う10個に絞る。/clear と /compact の差がいちばん効く」と指したガイド。2026-08-29 公開。ターミナル Claude Code の話。著者は aigeek 編集部（Claude が書いている、と本文が自己開示する）。

記事の実際の議論

コマンドは「お願いではない操作」の入口。/ 一文字で候補。セッション＝起動から終了までのひとまとまり。/help が全一覧。全部覚えるな、困りごとから引け。

まず10個を4ブロックに分けている。

重い・金が心配（4）：/context で現在地（公式：色つきマス目）。対処の前に打て。/clear は空コンテキストの新会話。消えるわけではない。/resume と /rewind から戻せる。名前付き /clear ログイン修正 は resume 一覧に残る。著者 Claude の一人称：/clear された瞬間から前の話は参照できない。この記事自体が clear 直後のセッションで書かれ、引き継ぎファイルを読み直した。/memory（CLAUDE.md）とセット。順番は「残す決めごとをファイルへ → そのうえで /clear」。/compact は同じやり取りを続け、長い部分を要約に置換。後ろに指示（/compact 実装の判断理由だけ残して）。何が残るかは公式 What survives compaction。/usage（別名 /cost）は利用量と費用。

FAQ の答えは短い。作業が終わっているなら /clear、同じ作業を続けるなら /compact。判断がつかなければ先に /context。

出し方を変える（3）：/model は次起動の既定にも保存される。セッションだけなら引数なしで一覧、行で s。/effort は起動オプションが low/medium/high/xhigh/max の5段（手元 2.1.243 の claude --help）、セッション中の /effort は auto / ultracode も。/help。

戻す（2）：/resume は一覧から。claude -c はそのフォルダの最新を一覧なしで続ける。/rewind はコードと会話をチェックポイントまで。Enter で戻る、d で説明、s で要約だけ、Esc で中止。git の前にこれを思え。

覚えさせる（1）：/memory で CLAUDE.md。

慣れたら6つ：/status /permissions /export /copy /doctor /mcp。一覧に出ない2つ：/rate-limit-options、/heapdump。バージョンで増減。/verify は 2.1.215 より前は自己判断でも走った。自作コマンドはスキルに統合（.claude/commands/deploy.md も .claude/skills/deploy/SKILL.md も /deploy）。

後編予告：/btw /loop /branch /subtask。出典は公式 Commands（2026-08-28 確認）と手元 2.1.243。編集メモ：/help は対話画面専用で自動実行できず取れなかった、と正直に書いている。下書きを別 Claude に反証させて3か所直した（clear は resume で戻せる、effort の数え分け、model の既定保存）。

体験

記事全文を読んだ。Claude Code 2.1.243 はこちらの箱に無く、/clear も /compact も打っていない。公式 Commands ページそのものはこのページでは開いていない。後編も未読。
