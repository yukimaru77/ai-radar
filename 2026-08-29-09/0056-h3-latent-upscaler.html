README が言うこと

低解像でサンプリング → このノードで latent を上げる → 目標解像で refine。bilinear/bicubic の ghost / double-image を避ける。LTX2.3 の latent upscaler に近い役割。時間は得て VRAM は得ない。refine は目標解像で走るのでピークメモリは直生成と同程度。

2バリアント（カテゴリ video/MinimaxH3）：2D は ResBlock + Temporal 3D-Conv、空間だけ、scale 1.0–4.0。3D はフル 3D-conv。resize は multiplier / target dimensions / megapixels。grid 揃え（default 32）。

2026-08-28 の News：MMH3 Split Upscale 3ノード（Temporal / Spatial Split Params + Split Upscale）。時間チャンクと空間タイル、seam denoise、二段 color match、triple temporal anchors。内蔵 upscale モデルは外し、外から pre-upscaled latent を受ける。08-26 は zero-copy load、chunk stride 24→32、上限 8192px / 16MP。ROCm オプションあり。

0020 側の注意：チェーンの handoff は upscale 前の decode から取る。upscale 後フレームを次ショットに渡すとキャストがドリフトする。
