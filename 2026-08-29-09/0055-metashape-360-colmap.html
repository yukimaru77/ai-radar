README 概要

Agisoft Metashape の equirectangular（球面）カメラ出力を COLMAP text に変換し、各360フレームから rectilinear crop（top/front/right/back/left/bottom）を切る。任意で PLY → points3D.txt（Open3D）。

Windows GUI バイナリは BOOTH。無料 Python に無い機能として Dual mask（equirectangular と cubemap を融合）、PNG 書き出し、カスタムマスク、RealityScan 用 XMP、360+平面 mixed（Metashape 側で Mixed SfM が先）、方向ごとの解像度レートとスキップ（空・地面・前後のテクスチャ/パララックスが薄い方向を間引く）。V1.0.0 まで changelog が並ぶ。座標変換は developer option、未サポート。

体験

README 先頭を gh した。Metashape も COLMAP も回していない。cubemap は見ていない。BOOTH は開いていない。
