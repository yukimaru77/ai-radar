Firecrawl（Keyless月1000）

https://www.firecrawl.dev/

「The context API to search, scrape, and interact with the web at scale。」今日開いたトップはエージェント向けの Search / Scrape / Interact / Map / Crawl。オープンソース、スターはサイト上 173.7K（gh の firecrawl/firecrawl は今日 173,654）。

料金ページで見た数字

/pricing を開いた。Free は 月 1,000 credits、$0、カード不要、同時2、低レート。Hobby $19/月（年払 $16）で 5,000。Standard $99 で 100,000。Growth $399 で 500,000。Scale $749 で 1,000,000。Enterprise はカスタム。

消費：Scrape / Crawl / Map / Monitor は 1 credit / ページ。Search は 2 credits / 10 results。Interact は 2 credits / ブラウザ分。JSON format は +4。Research Index の paper 系は無料。Agent プレビューは 1日5 run 無料のち動的。失敗は課金しない。セルフサーブは繰越なし（Scale/Enterprise のみ rollover）。pay-per-use は無い。

FAQ も同じ数字を繰り返す。「Is Firecrawl free? Yes, 1,000 pages every month (1,000 free credits per month).」エージェント向け onboarding は https://www.firecrawl.dev/agent-onboarding/SKILL.md。WorkOS ID-JAG が使えるなら /auth.md。

トップの CLI 例は npx -y firecrawl-cli@latest init --all --browser。Python SDK は Firecrawl(api_key="fc-YOUR_API_KEY")。P95 3.4s、96% coverage、93% fewer input tokens、と自称。ここはサイトの宣伝文で、こちらでは未計測。

Hermes への配線手順は 0004。このページは本体。

体験

トップと pricing を WebFetch / curl した。ダッシュボードにはログインしていない。API キーは作っていない。Search/Scrape は叩いていない（無料枠も燃やしていない）。docs.firecrawl.dev/mcp はドキュメントサイト自身の MCP マニフェスト（search_firecrawl_docs）で、製品 MCP mcp.firecrawl.dev/v2/mcp とは別物だった。
