r/DeepSeek、Vote4Andrew、score 1、コメント0。OpenCode から DSH へ数日。導入は問題なし、marketplace の plugin は「amazing」。複雑になると崩れる。自作 plugin（Creator Preset、3 sessions × 3 models: Qwen3-235B / Gemini 3.6 / Laguna 2.1 — いずれも OpenCode では問題なく動く）。Cordis plugin 文書を読ませ、既存 plugin を真似させる。

何が起きたか

モデルあたりツール呼び出しが数百、API も数百、入力トークンが数千万。cache hit が 0% と 60–70% のあいだ。毎分 tokens/minute 制限。ツール結果が空・失敗でも DSH は先へ進み「完了」と言う。roadmap の一段が落ちても remediation せず次へ。verify / test が弱い。sandbox できないと言われる。Qwen は「変更は許されずガイドだけ、ファイルを編集できない」と言った。単純なフォルダ移動すら大失敗。成果は「技術的には動くが plugin list / sidebar に出ない」1本。モデルのせいではない（OpenCode / LM Studio / Antigravity では同じモデルが動く）。学習曲線なのか、が問い。コメント0。

体験

長い selftext。DSH も OpenCode もこの比較タスクでは回していない。marketplace の厚みと fail-open な実行が同居する、という苦情。
