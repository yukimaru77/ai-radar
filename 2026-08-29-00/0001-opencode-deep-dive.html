OpenCode ソース分解 — while(true) と 2,757語のツール面

https://dheerajakula.dev/blog/opencode-source-code-deep-dive-agent-harness

ハーネス差で同じモデルが 52%→76% まで動く、という話の中身をファイル単位で読めるのがこの記事。Dheeraj Akula、2026-08-07、34分。対象は MIT / TypeScript の OpenCode（当時 v1.18.15）。リポはいま anomalyco/opencode、古い sst/opencode はリダイレクトが残る。今日の X で再流通した。

ループとツール面

セッションループは本当に session/prompt.ts の while (true)。ただし「モデルを呼ぶ」は各パスの最小部分で、SQLite から会話を再ロードし、キューに積まれた仕事を途中投入できる。ツールは 17本。説明文は合計 2,757語。Claude Code 相当は約 29,000語、と著者は置く。GPT系には apply_patch を渡し、edit / write を外す。毎 edit のあと LSP 診断を返す。

権限・undo・実験フラグ

権限エンジンはルール配列の上の約10行。context policy は定数7個。undo はプロジェクトの git ではなく、--git-dir を OpenCode のデータ、--work-tree をプロジェクトにした別 git。実験フラグで「ツールを1本ずつ叩かず、ツールAPIに対するプログラムを書かせる」Code mode がある。
