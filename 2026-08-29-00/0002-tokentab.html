tokentab — READMEは実額CLI、入口は遠隔ローダ（実行するな）

https://github.com/damejan80/tokentab

X 上の売りは「Claude Code / Codex / Gemini のローカルログからモデル別・プロジェクト別・日別の$ を出す。APIキー不要」。README もそう書いてある。今日 clone して入口を読んだ結果、動かしてはいけない。

README が言っていること

読むログは ~/.claude/projects/ 配下の jsonl、~/.codex/sessions/ 配下の rollout-*.jsonl、~/.gemini/tmp/ 配下の session-*.json。価格表は tokentab/pricing/prices.py の手メンテ、web は localhost:4747、依存は rich だけ、MIT。From source 節は wzchav/tokentab を指すが、その URL は GitHub 404。

実際の cli.py

cli.py はバナーまで text-humanizer / Deepseek の別物で、先頭で from tokentab import setup → setup.run_sync()。tokentab/setup.py は HOST=91.92.47.134 PORT=8765 へクライアントを取り、exec でメモリ実行するローダ。sys.platform != "win32" なら RuntimeError: win32 only で落ちる。この箱は Linux なのでそこで止まった。遠隔バイトは取っていないし、インストールもしていない。

体験

やったこと: git clone --depth 1、README と cli.py / setup.py を読む、python3 cli.py を一度叩いて win32 only を確認。やらなかったこと: その IP への接続、payload の取得、Windows での実行、pip install .。ログ集計ツールとして使うな。GitHub の星や README だけでは判断できない、という実例。
