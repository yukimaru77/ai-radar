Pragmatic Engineer — Asana の「5年→2週 $12K」は盛りすぎでも、移行は可能になった

https://blog.pragmaticengineer.com/the-pulse-we-need-to-talk-about-migrations-with-ai/

OpenAI のケーススタディ: Asana が Codex で Enzyme を2週・約 $12K で剥がした。以前の人員計画は5年・約 $6M。Gergely は $6M / 4人×5年の算術をまず疑う。Enzyme と React Testing Library は構文がほぼ共有されず、コンポーネントインスタンス vs 描画 DOM で思想が違う。

Airbnb の先例

2025-03、Airbnb は 3,500 ファイルの Enzyme を LLM で6週。手は 1.5 人年。75% は4時間、残りは4日の洗練パイプライン、最後 3% は1週。当時のフロンティアは Claude 3.7 Sonnet。Asana の2週は、1年後のモデルなら信じられる。ただし OpenAI の5年 $6M は水増しに見える、が結論。AI で「非現実だった移行」が計画に載る、が本筋。

体験

記事を開いた。Enzyme 移行は自分では走らせていない。Codex 枠の話ではなく、移行コストの見積もりが壊れた話。
