r/LocalLLaMA: 未信頼入力 ≠ 特権ツール、サブエージェントは default-deny

https://www.reddit.com/r/LocalLLaMA/comments/1w0q4xe/agent_harnesses_need_a_security_rule_untrusted/

r/LocalLLaMA、MoreIndependent5967、score 1、コメント0。原則: 未信頼の外部コンテンツを読むエージェントに、副作用ツールを持たせるな。Web / メール / docs は専用の read-only サブエージェント（WebReader / MailReader / DocReader）へ。メインは structured result だけを見る。メール読者は send/reply/delete できない。prompt injection が来ても特権ツールが無い。

default-deny

子は親 minus deny ではなく、ゼロ + 明示 grant。web_researcher は web read-only、coder は isolated workspace + tests、executor だけ副作用。制限はハーネスが enforce する（モデルの従順さに頼らない）。今夜の Talos / grith / LM Studio Auto Review と同じ問題意識を、ハーネス設計ルールとして書いた投稿。
