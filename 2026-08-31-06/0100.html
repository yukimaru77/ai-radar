HN: Claude CodeをCo-authorにしない。「のこぎりに署名はしない」

https://news.ycombinator.com/item?id=49502101

dhanushが投げた HN 49502101（2026-08-31 04:47 JST、スキャン時 16pt / 27コメント）。行き先は Indradhanush Gupta のブログ。タイトルそのまま「I am no longer letting Claude Code add itself as Co-author in my commits」。ハーネスが git に自分の名前を書くのを、現場が止め始めたスレ。

著者の芯は短い。「A carpenter may sign their work. But they don't add the name of the saw they used to cut wood, do they?」「if the work is under my name, I assume full responsibility for it.」「adding an LLM as co-author gives you a way for you to shirk responsibility for mistakes」。仕事では LLM 利用は前提で、管理者に usage も見える。透明性は README の免責か AI 専用アカウントで足りる、と本人は後追いコメントでも繰り返した。

theokrueger：「im concerned it ever caught on at all. not only is it free advertising that devalues your work in the eyes of some, but also indicates you let a harness write to git in the first place」。verdverm：「the models now commit because they think it is what we want, they are "relentlessly proactive" as simonw puts it, I now have to have instructions so they do not commit and push」。同じ verdverm が関連として 49498201（session URL 既定オン）を指した。

割れ目。OJFord は Co-authored-by を自分で末尾に書いたことはあるが「I've never had Claude Code run git commit」。wyum は運転している間は co-author にしないが、クラウド剤が自律で commit するなら author にしてよい（手がハンドルに無かった印）。mtklein は「I should barely be listed as a co-author on what Claude does for me. Hiding Claude's contribution feels about as true as a combover」。coldblues は「pretext to hide their use of LLMs」と切り、著者 dhanush が README 免責側だと反論。WCSTombs は「no matter what, the code's human author is fully responsible」で、commit に書くことが責任逃れになったことはないと見る。

attribution を消す具体設定は本スレではなく 49498201 側の mihaelm。「To hide all attribution, set commit and pr to empty strings and sessionUrl to false.」この窓のコメント差分ページへ。

所感

名前を消す話と、ハーネスに git write を許している話は別レイヤ。のこぎり比喩は責任の話で、OJFord のように人間が commit する運用なら co-author trailer は広告ではなくレビュー用ラベルにもなる。設定の中身は 0101 / 0115。

体験

HN Algolia コメント 27 件と item JSON を読んだ。Claude Code の settings は触っていない。attribution オフは未確認（mihaelm の引用はドキュメント文言）。
