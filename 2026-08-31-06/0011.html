Hand off the work. Get back the result. The open-source AI coworker for your team: agents with their own cloud computer, your tools and context, handing back finished work - websites, decks, spreadsheets, reports, PRs. Runs Claude Code, Codex, OpenCode on your subscription.

README が先に書く性質: Any agent, one interface（Codex は API key か ChatGPT subscription、Claude Code、OpenCode）。Durable runs（再起動後に live session を再プローブ）。Real sandboxes（Linux workstation、terminal / repos / browser / noVNC、MP4。Daytona と Cube）。Trusted gateway — credentials never enter the sandbox。Human-in-the-loop。Skills from GitHub（SKILL.md）。Slack-native。Native artifacts（DOCX / XLSX / PPTX / PDF）。

Quick start は bun と Postgres 16+ with pgvector。stock イメージには pgvector が無い、と明記。dev backend は 3201、frontend は 3400。Architecture の三点: エンジンはプラグ、すべての run は Postgres の event log、資格情報は sandbox に入らない。

ライセンスは AGPL-3.0-only。プロプライエタリ埋め込みは commercial license。CLA あり。Pi は Features では Claude/Codex/OpenCode が先で、Architecture 節で Claude Code, Codex, OpenCode, and Pi all speak one canonical event contract と足される。
