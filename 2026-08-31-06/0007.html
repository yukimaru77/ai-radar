Piは4点だけ。能不装就不装。全家桶もMCP山も要らない

https://x.com/Michaelzsguo/status/2094170796096659710

@Michaelzsguo の Pi 極小セット。方針は「能不装就不装」。主力は qwen3.8-flash。既出の CC background-wait リレーは窓前。今夜の新情報はこの4点。

1. pi install npm:pi-web-access（検索・リンク・GH clone・PDF・YouTube）
2. pi-openai-server-compaction（OpenAIモデルに Codex 風サーバ側圧縮。圧縮境界で状態を落とさない）
3. awesome-pi-themes（見た目だけ、golden-dusk）
4. steeringMode / followUpMode = all（誘導と追撃を一括送信）

「没有 agent 全家桶，没有一堆 MCP，Pi 保持简单，反而更好用。」

所感

隣の @eas4ai は Oh My Pi のルーティングがゲームチェンジャーと言い、こちらは足すものを4つ以上にしない。Pi の勝ち筋が「薄い」側に寄っている一次声。

体験

箱で pi は見つからなかった。help も command not found。追加パッケージは入れてない。4点の名前は本人ツイの原文。
