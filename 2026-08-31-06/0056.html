README: local MiniMax H3 video-generation service optimized for a single NVIDIA SM89 GPU. One bilingual Web console and REST API for FL2VA and Ref2VA。Base/LoRA hot switching、resource-constrained execution、checkpoint previews、native H3 second sampling。重み・アップロード・latent・生成動画はこのリポに含まれない。

Six isolated launchers: FL2VA and Ref2VA on logical 24GB INT8, 16GB INT8 and 8GB W4A8。Native generation from 360p through 1080p where admitted、plus native H3 second sampling up to 1440p on INT8 profiles。Optional ComfyUI HTTP connector that does not load a second H3 model。

Validated: RTX 4090 SM89、Linux x86-64 / WSL2、Python 3.10.20、PyTorch 2.13.0+cu130、CUDA runtime 13.0、service toolkit CUDA 13.3。Host memory 64GB effective minimum recommended。Other GPU architectures have not been release-validated。

Measured comparison は 14th Gen Intel Core i9, 128GB RAM, RTX 4090 24GB、INT8 FL2VA。ツイ側の 720p 約87s / 第二サンプリング約112s は README の比較動画（YouTube 43gOGaAlwnk）と並ぶ現場数字。Validation: 709 release tests passed, 4 skipped, 0 failed; 24 ComfyUI connector tests passed。
