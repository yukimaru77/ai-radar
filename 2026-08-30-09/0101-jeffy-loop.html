Jeffy Loop——エージェントに「終わった証明」を求める

https://github.com/lenamonj/jeffy-loop

Claude Code 向けの自律改善ループ。監査→1タスク検証→敵対的評価→レシートで「終わった」を証明する。Ralph 技法の上に、Anthropic / Boris Cherny 系の運用を方法論として載せた形。

何をするか

README より: /jeffy 10 で離脱可。公開面を地図化し、各タスクに runnable な受け入れ検査を付けたバックログを書く。反復ごとに1タスク、verify gate で壊れたら revert。「完了」は気分ではなく、fresh audit がクリーン、敵対評価が countersign、素のシェルが全体を再検査するまで許可されない。

レシート（外部マージ）

メンテナ無関係の OSS に入った修正例: bat PR#3862（piped 時に効かない security flag）、fasthttp PR#2343（Content-Length）、jsoncpp PR#1709（MSVC 未ビルド／wipe 不完全、2026-08-20 merge）、PapaParse PR#1135（resume 後ヘッダ重複、5.7.0）、chalk PR#687（メンテナ自身が直し）。

作者の HN コメント

@lenamonj: 「Jeffy Loop is an autonomous engineering system I built designed around one principle: agents should not merely produce work. They should produce evidence that the work is correct.」
