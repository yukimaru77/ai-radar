rtk-ai/rtk：端末出力圧縮でbashトークン削減（星は要警戒）

https://github.com/rtk-ai/rtk

Rust Token Killer。CLI proxy がエージェントの読む bash 出力を圧縮する単一バイナリ。README 主張は common dev commands で 60–90% 減。gh api 時点のメタ: stars 77828 / forks 4906 / language Rust / created 2026-01-22 / homepage https://www.rtk-ai.app 。@bkdgiffug が CC 週間星4位として紹介。

READMEが実際に言っていること

「High-performance CLI proxy that cuts up to 90% of the bash output your agent reads」。対応例: ls/tree を件数付きツリー、cat は signature 優先、grep は行截断、git status/diff/log 圧縮、テストは failures only など。overhead <10ms 主張。

重要 caveat（README原文）: "That is what RTK measures, and it is not the same as cutting your bill by 90%." bash 出力は input token の一部に過ぎず、prompt / system / history は別。

所感・宣伝臭

2026-01 作成で星7.7万・forks 4.9千は伸び方が異常に速い。機能自体（出力圧縮）は筋が良いが、星数をそのまま権威と見なさない。導入するなら実測の input token 差分で判断。
