GitHub: solodynamo/Ration — Claude使用量メニューバー

https://github.com/solodynamo/Ration

README 見出しどおり、Claude Code への依存度をデスクトップから見るネイティブ macOS メニューバーアプリ。

Install: brew install solodynamo/ration/ration、または Releases の Ration.dmg。「ad-hoc signed, not notarized」なので初回は right-click → Open。Homebrew ならその一手を自動化、と明記。

機能: 予算に対するリング（履歴から自動校正、オフも可）／プロジェクト・worktree 分岐別／7日トレンド＋共有用 recap（streak、busiest day、API換算$推定）。「100% local. Reads Claude Code's own session logs off disk. No accounts, no network calls」。

ビルド: swift build && swift test、macOS 13+ / Xcode 16 / Swift 6。./Scripts/build_app.sh → dist/Ration.app。Provider 追加は UsageProvider を1型書くだけ、と README。

所感

ネットワーク無しで session log だけ読む設計は、クォータ灰ツールより監査しやすい。
