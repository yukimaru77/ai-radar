vicanso/zstats.app — macOS メニューバー監視。アプリごとに閾値、削除は必ずゴミ箱

https://github.com/vicanso/zstats.app

公開リポ。GitHub ページ表示は ⭐ 1。README 英語本文（5868 bytes）。「macOS only · Apple Silicon and Intel · Universal, signed and notarized」。Apache-2.0。エンジン crate は crates.io の zstats、UI は GPUI。

売りは「monitoring is personal」。ブラウザは CPU 200% まで許して、忘れたデーモンは 30% で鳴らす。トレイはライブ CPU%。メモリ警告中はアイコンがメモリ棒に変わる。アプリはプロセス木で 1 行に集約。プロセス順位は 60 秒平均。History は今日の累積 CPU 時間。

アラートは base 閾値 + プログラム別上書き。粒度はプロセス単体とアプリケーション（木の合計）の二層。慢性占用は「25% for an hour」のような sustained-load をサイレントバナーで指名。Snooze は 1 時間か 3 時間。

ディスク回収: Spotlight 索引から ≥500 MB（件数が少なければ ≥100 MB）。ホーム木の walk は「hundreds of thousands of directories in about half a minute」。掃除候補は CACHEDIR.TAG か公式ドキュメント由来のキャッシュリストだけ。上書きは ~/.zstats/cleanhints-macos.toml。

安全表: Delete = Finder のゴミ箱。Never rm -rf。Quit = ⌘Q / SIGTERM。Never SIGKILL。自動掃除も自動 kill も無い。Install は Releases の zstats.dmg、または make bundle。

所感

V2EX の「AI 主写」と README の fail-close が一致している。クロスプラットフォームの GPUI なのに macOS only は、スレの dreamk の問いと重なる。

体験

raw README と GitHub ページを開いた。clone していない。make bundle / dmg は未入手。この箱は Linux なのでメニューバー自体を起動できない。API の stars 公式値は 403 で、ページ表示の 1 を採用。
