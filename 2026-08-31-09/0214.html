苏灿烤鱼: 「不是又一个RAG套壳。它把整个代码库编译成一张可查询的知识图谱，连小模型都能拥有架构师视角。」

苏灿烤鱼: 「你让AI助手改一个UserService.validate()方法，它改得很流畅，注释也补得漂亮。三天后，线上炸了：有47个函数依赖这个方法的返回类型，AI一个都不知道。这不是你用的模型不够聪明。这是所有AI编程工具的结构性缺陷：它们能看到代码的"字"，却看不到代码的"骨架"。」

苏灿烤鱼: 「这个项目2025年8月才创建，一年时间拿下超过4.6万星…最新版本v1.6.10在2026年8月底刚刚发布。它的定位说得很直白："The nervous system for agent context"」

苏灿烤鱼: 「README里还有一句更狠的对比："像DeepWiki，但更深。DeepWiki帮你理解代码，GitNexus让你分析代码。"」

Cursor / Claude Code / Codex の関数探しは grep と embedding。「这些关系藏在AST里…grep和向量检索对它们天然失明。」核心は「把结构计算从查询时挪到索引时」。利益の三層: 可靠性、token效率、模型平权。

CLI: npx gitnexus analyze で索引、npx gitnexus setup が Claude Code / Cursor / Codex / Antigravity を自動検出。索引はローカル .gitnexus/、全程無網絡。MCP 17 ツール（impact / trace / detect_changes / Cypher）。ライセンス PolyForm Noncommercial。
