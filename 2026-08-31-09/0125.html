Ian Macomber: Post-AI Data Stack の形と感触

https://www.iandmacomber.com/blog/post-ai-data-stack/

August 30, 2026。データスタック進化でデータサイエンティストの blast radius が広がってきた、という俯瞰。2013 pre-modern → 2016 cloud DW → 2020 Modern Data Stack+Reverse ETL → 2026 Post-AI。

核心: 「AI makes producing analysis cheap. It does not make agreeing on reality cheap。」今日の二職: (1) 全員が正確・強力・独立にデータ+AIで作れるようにする (2) 会社が動く単一の現実を作り擁護する。コーディング剤・AIネイティブベンダー・Slackbot 分析で誰でも物語を量産できる時代、希少資源は全社合意。

Post-AI スタックは専門家判断をインフラに埋め、部屋にデータサイエンティストがいなくてもエージェントが正しい分析を出す方向。節立てに Agent-Readable Artifacts / Agent-Operable Tools / Agent-Agnostic Context / Agent-Testable Consensus など。

所感

「分析生成」から「現実の合意インフラ」への職能シフトの言い切りが強い。
