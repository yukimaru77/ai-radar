沈黙王二: 「昨天有读者在评论区留言说，“我觉得豆包工作会很快起来，并且到第一！因为飞书+豆包这个体系我感觉确实是很能打。” 你别说，深度体验了一天后，深有同感。」

沈黙王二: 「豆包工作，一个全新 AI 办公 Agent，能自己拆解任务、操作你的电脑、直接把结果写进飞书云文档。你说一句话，它干完交活。跟飞书是原生打通的…我在本地已经下载安装了。」

二モード: 本地电脑と云电脑（24 時間 VM）。「就是你本地的电脑关机了、睡眠了，任务照样可以切换到云电脑继续跑。」

派活の実例（自作「派简历」）: 「帮我写一篇派简历的宣传文档…写完输出到飞书文档。然后再帮我更新一下 GitHub 主页的 README」→「它在我电脑上找到 GitHub 仓库的readme进行修改，完事后直接帮我 commit（我用的是 Auto 模式）。整个过程我就输入了一段话，中间没切过任何窗口」

配図を渡して「反推出风格描述和可复用的 Skill」。内蔵は Seedance（動画）と Seedream（画像）。飛書多次元表を読ませて棒グラフと円グラフ。「甚至自己安装了 matplotlib」「我不需要先把飞书文档导出成 CSV」。

締め: 「之前用其他的 AI 办公工具，总得在下指令和动手干之间来回切。搞得最后还不如自己动手。豆包工作把中间这层搬运工作给省了。」

公式入口として本文は www.doubao.com/work。デモ題材のリポは itwanger/PaiResume。

所感

オフィス Agent の現場: 成果物が飛書ドキュメントと GitHub commit で終わる。Auto モードで commit まで任せる、という点がハーネス話。
