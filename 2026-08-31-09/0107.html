GitHub: gsttm/norms — .norms/ から各エージェント規則を生成

https://github.com/gsttm/norms

「Define your coding rules once, store them in Git, and make every coding agent follow them。」Canonical は .norms/ の Markdown。例: id testing.integration、applies_to packages/**。

norms sync が生成するアダプタは現状4つ: AGENTS.md、CLAUDE.md、.cursor/rules/norms.mdc、.github/copilot-instructions.md。生成物は編集せず .norms/ を編集、と明記。

Install: curl -fsSL https://raw.githubusercontent.com/gsttm/norms/main/install.sh | sh（checksum 検証、VS Code 拡張は任意）。コマンド群: init / list / context / explain / lint / status / propose / sync / check / review。

所感

「ルールをエージェントごとにコピペ」から脱する方向。生成アダプタが4系統に閉じている点は Codex 等を足す余地。

体験
