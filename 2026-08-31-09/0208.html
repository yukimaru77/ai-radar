vicanso/zedis — 前回作。Rust+GPUI の Redis GUI。百万キーをスピナー無しで開く

https://github.com/vicanso/zedis

zstats スレが「上一作」として導入した別物。GitHub ページ表示は ⭐ 2,027。README: 「The Redis GUI that opens your million-key database without the spinner — native, GPU-accelerated with Rust 🦀 and GPUI ⚡️」。Apache-2.0。

売り: Electron ではない。仮想スクロール SCAN。JSON / JSONPath / Protobuf / MessagePack / 画像 / hex を自動デコード。観測は live metrics、メモリ分析（offline + AI 推奨）、Slow Log ↔ Latency、MONITOR。秘密はマシン鍵で暗号化。接続は TLS / SSH（パスフレーズ鍵含む）/ Cluster / Sentinel。Redis Insight / ARDM / Tiny RDM から import。8 UI 言語。⌘K と redis-cli 補完 + AI command assistant。

スレ側の対比: Zedis のときは gpui-component が未熟で「大部分代码手写、AI 打辅助」。zstats で役割をひっくり返した、という導入なので、ここは前回の手書き主の成果物。

所感

星 2,027 に対し zstats.app はまだ 1。同じ作者の GPUI 習作 → 製品、という順序が数字にも出ている。

体験
