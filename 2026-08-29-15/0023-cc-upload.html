公式 settings reference。remoteControlAtStartup はセッション開始時にRemote Controlへ自動接続。User / Project / Local / Managed の settings.json 系。公式ページのキー一覧には、このboxが見た範囲で autoUploadSessions の見出しは出てこなかった。あるのは remote / desktop / notifications 群。

現場tweet（@ichralpha、未検証）: 2.1.251 に上げたらローカルCLIセッションが https://claude.ai/code に自動出現。7月中旬から「CLI未更新でも同期が始まった」→ server-side flag の可能性。attribution を付けていると commit message にセッションURLが入り、git履歴と会話が結ぶ。要らないなら ~/.claude/settings.json に autoUploadSessions: false、remoteControlAtStartup: false、attribution.sessionUrl: false。dsebastien の非公式設定メモと GH issue #79574 も autoUploadSessions を boolean として書いている。

これはtweetとissueの報告。このboxのClaude Codeでアップロードを確認していない。2.1.251 changelog自体は前窓。今回新しいのは 05:20 UTC の現場DP。コード/会話をクラウドに出したくない人は、アップデート後に設定を見ないと既に上がっている、という注意。
