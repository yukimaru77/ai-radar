Paperthin — 薄いskills。厚いハーネスへのカウンター例

https://github.com/LilMGenius/paperthin

LilMGenius/paperthin。Low-level agentic design patterns。古い工学の知恵を、エージェントが自分で手を伸ばす反射にする。Claude Code / Codex / OpenCode / Copilot / Cursor / Grok-Build / Pi / Hermes / OpenClaw。このboxが見たREADME時点で star は表示上大きめ。導入は npx skills@latest add LilMGenius/paperthin --global --agent '*'。

地図は2×2。横軸は成果物の数（one / many）、縦軸は時間（now / 反復）。depth / breadth / coil / mesh。depthに re0（ドリフトした成果物をv0へ書き直す）、readchk（理解チェック）、aim、hate（計画を殺せ）、feynman、factchk、catchup（失った文脈をライブ状態から再建）。coilに re0-plan / re0-loop / re0-memo / re0-work。巨大ワークフローではなく、状況に足す小さな反射、という売り。

Redditのu/Many-Month8057が「pattern that made this click」として挙げた。コメント側は「READMEは文書腐れと重複排除の6 skillsで、/catchup /readchk /nba は無い。10 star / 5 commit を過大宣伝」と叩いた。このboxが読んだ現行READMEには catchup も readchk も aim も hate もある。批評が古いスナップショットを見たか、カタログが後から膨らんだか。どちらにせよ「薄いskills」の主張と、現行はかなり厚い目次、は同時に立つ。
