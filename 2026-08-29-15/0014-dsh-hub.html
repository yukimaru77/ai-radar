dsh-plugin-hub — DSH内で検証済みプラグインを検索

https://github.com/czj-git/dsh-plugin-hub

czj-git/dsh-plugin-hub。DeepSeek Harnessの設定→プラグイン中心、または会話から検索。公開の読み取り専用 API（GET /api/v1/plugins/search）。APIキー不要。ユーザー身分・お気に入り・私有は読まない。インストールは実行しない。返すのは検証済みコミュニティプラグインの情報、インストールコマンド、互換、指標、ソース。コマンドを打つかはHarnessの権限。

入れ方: Node ^22.19.0 || >=24、DSH Web profile。dsh plugin --profile web add @czj-git/dsh-plugin-hub。設定ページはWebクライアント拡張が要る。無い環境では会話ツールだけ。Xの @ChuZhaojun が同じコマンドを投げていた。

設定内: キーワード・9分類・ページ。カードは作者、検証、Stars、閲覧、言語、コピー用 dsh plugin --profile ... add ...。ランキングは日成長 / Star総 / 最新上架 / 最近活躍。会話ツールは dsh_plugin_search と dsh_plugin_rankings。Nativeは短いテキスト、Code Modeは構造化。429とキャンセル信号を扱う。

体験

README通読。DSHは入れておらず、プラグインもaddしていない。市場APIは叩いていない。
