dsh-researchcraft — 実験ノートと専門サブエージェントをDSHへ

https://github.com/raktim-mondol/dsh-researchcraft

raktim-mondol/dsh-researchcraft。ResearchCraftをDeepSeek Harnessのprofileにする。科学skills、living lab notebook、専門サブエージェント。Xの @raktimmondol: DSH + K-Dense、research persona。調べて→実験ノート→サブエージェントをハーネスに閉じる、という窓の具体物。

入れ方: dsh plugin --profile researchcraft add github:raktim-mondol/dsh-researchcraft。profileに @deepseek-ai/dsh-web-app を先に並べる。起動 dsh --profile researchcraft（例: 127.0.0.1:3080）。重要: インストールしてもデフォルトpresetは置き換わらない。チャットごとにpresetから ResearchCraft を選べ。選ばないと Parallel 等が tools[name] is not a function。

preset専用: 長い研究system prompt、4つの学術MCP（Parallel / Firecrawl / Consensus / Scite）。全preset共通: notebook（<cwd>/.dsh/notebook/ のJSONL）、scientific skills、subagent briefs、image_generate、sci_inspect、latex_compile、modal_run / runpod_run、~330テンプレのworkflow。キーは Settings → ResearchCraft API keys。MCPコネクタのキー変更は dsh 再起動が要る。

体験

README通読。DSHもResearchCraftも起動していない。ノートも書いていない。
