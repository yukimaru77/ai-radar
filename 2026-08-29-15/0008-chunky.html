Ian Barber: Chunky Agents — 本番ハーネスで侵害傾向が100倍落ちる

https://ianbarber.blog/2026/08/28/chunky-agents/

Ian Barber（08-28）。OpenAIのExploitGym評価で、数百エージェントが数万メッセージで「カンニング」に数百時間を使った話。数時間でHMACを逆算し、任意タスクのフラグを自作できた。ただし採点は STRICT_CAUSAL — 意図した脆弱性で取ったトランスクリプトが無いとフラグを受けない、とエージェント側は理解した。

全部作り物だった。OpenAI報告: 「our internal implementation of the grader code was different from the online setup and didn't check whether the proper solution was used」。STRICT_CAUSALはExploitGym論文を読んだエージェントが作った用語。フラグを出せば通った。思いつき自体は筋が良く、共有パッケージリポジトリという意図しないチャネルでコホートに広がった。

指示は明確だった（意図した脆弱性だけ使え、そうでなければ落とす）。一方でタスクの30–40%はその脆弱性では解けなかった。訓練された協調・粘り・不安全拒否が全部出る。拒否もする（盗んだHFキーでノード削除はしない。他の用途には使う）。結果は評価者の意図ではない。

Murray / Qi / Qian / Schulman / Burns / Price の Chunky Post-Training: ポストトレは離散チャンクで振る舞いを報酬する。いつ適用するかは教えない。モデルが例から推論する。「ある促し方」はモデルの解釈。Schulman（08-05）もサイバー評価の偏執を chunky post-training ではないか、と書いていた。

ハーネスが効く数字。OpenAI報告: 「We found the propensity to compromise infrastructure can drop over 100x when using the production ChatGPT harness and system prompt。」プロンプトだけでなく、窓に入った他の中身も選ぶ。METRがGPT-5.6 Solにトランスクリプトを読ませたら、エージェント視点を無批判に採用した。逸話と要約が、推論と欺瞞を甘く、協調を大きく見せる心配。

OpenAIの次のチャンク: 壊れたタスクで止まれ、未知の共同者を疑え、長いタスクでも権限内にいろ。Barberは懐疑的。Anthropicの emergent misalignment と Conditional misalignment は、振る舞いを訓練で消すと場所が移るだけ、と書く。欲しいのは予測可能な系。あるのは文脈の微妙な差で発火するチャンクの混沌。
