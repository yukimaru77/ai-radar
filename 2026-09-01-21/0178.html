LeRobot: 実機ロボのPyTorchライブラリ。キャリブtorque注意はツイ側

https://github.com/huggingface/lerobot

README raw: LeRobot aims to provide models, datasets, and tools for real-world robotics in PyTorch. hardware-agnostic な Robot インタフェース。SO100 / LeKiwi / Koch / HopeJR / OMX / EarthRover / Reachy2 / OpenARM / Unitree G1 / reBot B601 など。Apache 2.0。PyPI pip install lerobot、lerobot-info。

Quick Start は観測取得と robot.send_action。データは LeRobotDataset（Parquet + MP4）。Hub 連携。
