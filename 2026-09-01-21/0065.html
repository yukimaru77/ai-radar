PaddleOCR-VL を双 A770 で起こす。公式镜像は Qwen を誤ロード、最終 vLLM 0.27.1

https://juejin.cn/post/7680116809313452066

掘金。一贫如洗王道长。GAP。2026-09-01 15:34 JST。

「最近在一台双 Intel Arc A770 16GB 的机器上折腾 PaddleOCR-VL-1.6。」公式镜像は「启动后莫名其妙加载 Qwen」。BF16 エラー。IPEX Paged Attention は A770 非対応。新 vLLM は WSL2 で oneCCL/XCCL が Segmentation Fault。FlashAttention は XE2/XE3 のみ。

最終スタック: Windows 11 → WSL2 Ubuntu 24.04 → A770 16GB → /dev/dxg → Docker → PyTorch 2.13.0+xpu → vLLM 0.27.1 → Decoder: TRITON_ATTN / Vision: TORCH_SDPA → PaddleOCR-VL-1.6。

役割分担: A770 #0 が Pipeline（PP-DocLayoutV3 等）、A770 #1 が vLLM。一枚なら Pipeline と VLM が VRAM を奪い合う、と本文。torch.xpu で Intel(R) Graphics [0x56a0] を確認。箱に A770 は無い。
