Tibo Reset Forecast: 公式Reset発言と過去間隔だけの説明可能な目安

https://attrip.jp/tibo-reset/

個人製。ブランド表記は Codex / Reset forecast。ヒーローは「次のRESET、いつ来る？」系。24h / 3d / 7d の枠と NEXT RESET WINDOW がある。静的HTML上の数値は -- （JS描画）。

ページ内コピー: 「公式Reset発言と過去間隔だけを使う、説明可能な目安です。願い数や外部予測値は使いません。」英語: An explainable estimate from Reset text and past spacing only. No wish count or external forecast probability.

データ: https://codex-resets.com/api/v1/resets?limit=100&from=2026-01-01T00:00:00Z&order=asc と status API を5分ごとに読む。失敗時は同梱 data.json snapshot。負例が少ないため確率は過信するな、と書いてある。announced_at は実行時刻ではない、因果は未確定。

架空設定 / FICTIONAL COMPANY として「リセットカンパニー RESET COMPANY」、CEO: Tibo（非公式のジョーク）。MISSION「みんなに、もう一度つくる余白を。」所蔵作品は RESET を押す5つの瞬間。

告知ツイは別ページ。

所感

作業カレンダーに Tibo 連発を落とす用途。確率UIはライブJS。過信するな、が本体。
