同じモデルでも分岐するのは制御の渡し方 — CC / Codex / DSH / Pi

https://x.com/ClarissaLexber/status/2094707597526081630

@ClarissaLexber（08:43 UTC）。実測ベースで4経路を切った。スキャンの要約は「同じモデルでも harness が決める」。軸は強さ比較ではなく、どこまで先に決めて、どこを返すか。

Claude Code: Plan / Sub-agent / Hooks / Skills / MCP / plugins が揃い、CLI・IDE・Web・Mobile まで入口がある。Anthropic が正解を先に選んでくれる完成品。仕事を回すならまだ最初に来る、という位置づけ。

Codex: Sandbox / Approval / Network Policy。自動 Review は「別 Agent が実行可否を裁く」。大胆に働かせつつマシンを壊させない方向。

DeepSeek Harness: Everything is a Plugin。Plan / Sub-agent / models / Tools / Sessions をプラグイン化。tool calling は Native Mode と Code Mode。DeepSeek 以外（Anthropic / OpenAI / custom）も繋げるが Developer Preview、Breaking Changes 前提の実験場。

Pi: Sub-agent / Plan / Sandbox を Core に入れない。Extension / Skill / Package。Context が薄く、無限にいじれる。

原文: “what really matters is this: how much does it want to decide for the user, and how much control is it willing to give back to you?”
